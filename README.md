# 心情收支簿

> AI 驱动的消费心理学记账工具。记录每一笔，看见情绪与金钱的隐秘关联。

---

## 特性

### 🧠 心理学记账体系
- **消费五型：** 必要 / 价值 / 情绪 / 冲动 / 意外 —— 基于 Kahneman 双系统理论与 Dittmar 消费文化理论
- **收入分类：** 工资 / 兼职 / 理财 / 红包 / 其他
- **8 种心情标记：** 开心、平静、一般、难过、焦虑、愤怒、兴奋、疲惫
- **理论基础：** Kahneman 双系统、自我决定理论（SDT）、心理账户理论、控制点理论

### 🤖 AI 智能记账
- **自然语言记账：** 一句话描述 → AI 自动提取金额、分类、心情
- **三合一助手：** 财务报告 / 心理分析 / 对话助手
- **常用模板：** 自动生成高频交易快捷入口

### 🎤 百度语音识别
- 点击录音 → 语音转文字 → AI 解析记账
- PCM 16kHz 单声道转换 + OAuth 2.0 Token 缓存

### ⭐ 心愿 × 星光
- **心愿：** 设定长期储蓄目标（旅行、学习、大件物品）
- **星光：** 每次守住消费冲动 +1 ⭐
- **守护金额：** 守住时的金额自动计入心愿进度
- **StarJar 可视化：** SVG 环形进度条 + 浮动星光粒子

### ❄️ 欲望冷却
- AI 分析消费冲动（类型 / 渴望度 / 必要性 / 风险因素 / 反思问题）
- 手动选择冷却期（1h ~ 30d）
- 冷却期满重评估：守住 / 购买 / 再冷静
- **成长轨迹：** 守住率、守住总金额、星光总数 + 事件时间线

### 📊 数据可视化
- 消费类型 Donut 环形图 + 消费心情 Pie 饼图
- 14 日收支流双面积图（收入绿 / 支出红）
- 心情时间线（14 天横向滚动）
- 月历热力图（支出/收入双视图）
- 消费分类柱状图 + 心情 × 消费柱状图

### 💰 月度预算
- 设定每月消费上限 → 实时进度条 → 超支亏空追踪
- 预算盈余可转入心愿

### 🎨 主题配色
- **动态心情：** 主题色跟随当月主要心情自动变化（8 种心情 × 3 种跟随策略）
- **固定配色：** 6 种预设（暖琥珀 / 森绿 / 海蓝 / 玫瑰粉 / 薰衣草 / 日落橙）
- **暗色模式：** 跟随系统或手动切换
- 全局联动：页面背景、卡片色阶、按钮、极光背景全部跟随

### 📱 体验
- 移动优先响应式设计 + iOS 安全区适配
- 封面动画（物理引擎浮动图标）
- Canvas 粒子网络背景 + 点击粒子溅射
- Ctrl+K 快捷键触发记账
- 新手引导 + 分类悬停说明

### 🔒 数据自主
- 所有数据存储在浏览器 IndexedDB，无需注册、无需登录
- API Key 使用 AES-GCM 256 位加密
- 支持 JSON/CSV 导出导入
- 一键清除所有数据

## 快速开始

```bash
git clone https://github.com/TRY-0508/Auto-Money.git
cd Auto-Money
npm install
npm run dev
```

打开浏览器后进入「设置 → API 配置」填入 DeepSeek API Key（从 [platform.deepseek.com](https://platform.deepseek.com) 获取）。

语音功能需额外配置百度语音 API Key（免费额度 5 万次/年）。

## 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 6 |
| 样式 | Tailwind CSS 3 + CSS 自定义属性 |
| 状态 | Zustand |
| 数据 | Dexie.js (IndexedDB) |
| 路由 | react-router-dom v6 (HashRouter) |
| 图表 | Recharts |
| AI | OpenAI SDK → DeepSeek API |
| 语音 | 百度 REST API + Web Audio API + MediaRecorder |
| 加密 | Web Crypto API (AES-GCM) |
| 图标 | Lucide React |
| 部署 | GitHub Pages + Actions CI/CD |
