# 心情收支簿 — 版本记录

## v3.0 — 消费心理全面转型（当前）

### 核心变更
- **心理学分类体系**：支出五型（必要/价值/情绪/冲动/意外）+ 收入五型（劳动/增值/馈赠/惊喜/回流）
- **全局主题系统**：6 种固定配色 + 8 种动态心情配色，全界面联动
- **月度预算**：预算跟踪 + 盈余转入心愿 + 亏空优先填平
- **冷却时间手动调整**：6h~7d 可选
- **Dashboard 卡片化**：四统计卡 + 扇形图 + 柱状图 + 30日面积图
- **AI 助手重设计**：卡片化布局 + 双图表 + 数据概览条
- **卡片色阶系统**：五级底色（accent/stat/chart/list/soft），CSS 变量驱动
- **新手引导**：首次访问展示引导卡片 + 分类悬停说明

### 技术变更
- DB v5→v7（清理旧分类 + 强制迁移）
- 新增 `deficits` 表
- Settings 新增 `themeMode`、`fixedTheme`、`colorScheme` 字段
- 新增 `bg-primary-gradient` / `text-accent` 等主题 CSS 类
- 删除 `appStore.ts`、`speech.d.ts`

## v2.0 — 心愿 + 冲动冷却

- 心愿目标管理 + StarJar 星光可视化
- 冲动冷却系统：AI 分析 → 冷却期 → 到期重评估 → 守住/释怀
- 成长轨迹：守住率 + 守住金额 + 星光总数 + 事件时间线
- 记录冲动表单支持 AI 心理分析（风险因素、反思问题、建议冷却）
- 重评估弹窗（渴望程度滑块、反思记录、守住/释怀/再冷却）

## v1.0 — 基础记账

- AI 自然语言记账 + 百度语音识别
- 8 种心情 + 四型消费分类
- Dashboard：Bento 网格 + 心情 Banner + 饼图 + 时间线 + 月历
- AI 助手：财务报告 / 心理分析 / 对话
- 设置：API · 分类 · 分账单 · 数据管理
- 封面 SplashScreen + Canvas 粒子网络
- GitHub Pages 部署
