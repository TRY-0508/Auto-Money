# 心情收支簿 — 版本记录

## v3.0 — 当前版本（消费心理学版本）

### 核心记账体系
- **消费心理学五型分类：** 必要消费、价值消费、情绪消费、冲动消费、意外消费——基于 Kahneman 双系统理论与 Dittmar 消费文化理论
- **收入传统五分类：** 工资、兼职、理财、红包、其他——简化自更早版本的心理学收入分类
- **8 种心情标记：** 开心、平静、一般、难过、焦虑、愤怒、兴奋、疲惫——每次记账可选
- **分类描述浮层：** 悬停系统分类显示心理学理论基础和归类依据

### AI 智能记账
- 自然语言 → 结构化记账数据的自动解析
- 支持文字输入和语音输入两种方式
- 三步骤流程：输入 → AI 解析确认 → 手动微调保存
- 常用记录模板（基于历史高频交易自动生成）
- 货币符号自动格式化（软妹币 ¥）

### AI 三合一助手
- **财务报告：** 支出分类柱状图 + 预算进度 + AI 生成的月度财务报告（Markdown 格式，温暖语气）
- **心理分析：** 心情 × 消费柱状图 + AI 消费心理学分析（情绪-消费关联 + 改善建议）
- **对话助手：** 带数据上下文的自由对话，支持预设快捷提问

### 数据可视化
- 消费类型 Donut 环形图（含中心金额展示）
- 消费心情 Pie 饼图（8 种心情颜色映射）
- 14 日收支流双 Area Chart（收入绿 + 支出红）
- 心情时间线（14 天横向滚动，含心情图标 + 支出金额）
- 月历热力图（支出/收入双视图，点击查看日期汇总，左右滑动切换月份）

### 欲望管理系统
- **心愿（JarGoal）：** 长期目标设定，StarJar 环形进度条 + SVG 渐变光泽 + 浮动星光粒子 + 点击查看守住记录
- **欲望冷却：** AI 分析消费冲动 → 用户选择冷却期（1h/3h/6h/12h/1d/2d/3d/7d/14d/30d）→ 到期重评估
- **冷却倒计时：** SVG 环形进度，颜色从蓝→橙→红逐渐变化
- **提前守住：** 冷却中即可确认守住（不等冷却期满）
- **重评估流程：** 守住（星光+1, 金额计入心愿）/ 购买（标记已购买）/ 再冷却
- **AI 冲动分析：** 冲动类型判断（情绪/冲动/不确定）、渴望程度 1-5、必要性 1-5、10 种风险因素识别、建议冷却时长、反思引导问题
- **成长轨迹：** 守住率、守住总金额、星光总数统计 + 事件时间线 + 筛选（全部/已守住/已释怀）

### 主题系统
- **6 种固定配色：** 暖琥珀（默认）、森绿、海蓝、玫瑰粉、薰衣草、日落橙——每种均有明暗双模式
- **8 种动态心情配色：** 开心、平静、一般、难过、焦虑、愤怒、兴奋、疲惫
- **3 种跟随策略：** 最多心情（频次最高）、最新消费（最近一笔）、全天适应（当日最后一笔）
- **覆盖范围：** 页面背景渐变、5 级卡片色阶、按钮渐变、Aurora 极光背景、文字强调色
- **暗色模式：** `.dark` class 切换，跟随系统（prefers-color-scheme）或手动切换

### 月度预算
- 每月设定消费上限
- 首页四象限中实时显示预算剩余和彩色进度条（绿→黄→红）
- AI 报告中包含预算执行分析
- 超支形成亏空记录

### 数据管理
- **分账单（Project）：** 创建独立收支分类（如春节旅游、游戏开支），首页支持切换查看
- **数据导出：** JSON（完整备份）、CSV（仅交易记录，BOM 头兼容 Excel）
- **数据导入：** JSON 文件恢复（bulkPut 批量写入）
- **数据清除：** 一键清空所有 IndexedDB 表
- **API Key 加密：** AES-GCM 256 位加密存储于 IndexedDB

### 交互与体验
- 封面动画（物理引擎驱动的浮动图标碰撞反弹）
- Canvas 粒子网络背景（80 个粒子 + 线条连接）
- 点击空白处溅射彩色粒子
- 键盘快捷键 `Ctrl+K` 触发记账
- 新手引导（消费五型介绍 + 三步上手指引）
- 台阶式入场动画（stagger delay）
- 卡片悬停效果（上移 + 阴影增强、3D tilt、shine 光泽）
- 按钮微交互（缩放 + 渐变光泽动画）
- 确认弹窗动画（弹入 + 毛玻璃背景）
- iOS 安全区适配（safe-area-inset-bottom）

### 语音识别
- 百度语音 REST API 集成
- MediaRecorder Web API 录音
- Web Audio API PCM 16kHz 单声道转换
- OAuth 2.0 Token 缓存（localStorage + expires）
- 直接请求 + CORS Proxy 降级双通道

## 待优化项

以下为计划中但尚未实现的功能和改进：

- **PWA 离线支持：** 配置 Service Worker，实现断网可用和"添加到主屏幕"
- **移动端手势优化：** 月历左右滑动更流畅、下拉刷新、长按操作
- **AI 输出安全：** 对 AI 生成的 HTML 报告做 XSS sanitization（如集成 DOMPurify）
- **推送通知：** 冷却到期提醒、每日记账提醒
- **测试覆盖：** 单元测试（Vitest）+ 端到端测试（Playwright）
- **暗色模式完善：** 硬编码的颜色类（如 `bg-gray-50`）改为 CSS 变量驱动的暗色适配
- **Markdown 渲染增强：** 支持表格、代码块、嵌套列表
- **多标签同步：** IndexedDB 跨标签页数据同步
- **多币种支持：** 当前硬编码 CNY，可扩展为动态货币格式
- **预算分类拆分：** 为每个消费类型单独设定预算
- **周期报告：** 周报、季度报告
- **数据图表增强：** 趋势预测线、同比对比
- **导出发送：** 通过邮件/微信发送备份文件
