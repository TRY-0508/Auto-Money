# 心情收支簿 — 总体设计方案

> AI 驱动的消费心理学智能记账与欲望管理工具 · 单页应用 · 本地优先

---

## 1. 产品定义

### 1.1 一句话描述

帮助用户**看见消费心理模式、暂停冲动、清醒选择**的 AI 陪伴工具。

### 1.2 核心隐喻

每次面对冲动时的清醒选择 = 一束**星光** → 星光积累 → 点亮**心愿**

### 1.3 设计原则

| 原则 | 含义 |
|------|------|
| **温和** | 不审判、不施压，像朋友对话 |
| **清晰** | 信息层次分明，一眼看懂 |
| **有层次** | 五级卡片色阶区分功能区 |
| **丰富** | 图表替代文字，但不堆砌 |
| **始终如一** | 同一语义用同一颜色 |

## 2. 心理学理论基础

### 2.1 消费五型（Kahneman 双系统 + Dittmar 消费文化）

| 类型 | 系统驱动 | 核心理念 |
|------|---------|---------|
| 必要消费 | System 2 理性 | 维持基本生存运转 |
| 价值消费 | System 2 理性 | 对齐长期目标、自我成长 |
| 情绪消费 | System 1 直觉 | 情绪状态的消费投射 |
| 冲动消费 | System 1 突发 | 无计划即时决策 |
| 意外消费 | 外部事件 | 突发不可控支出 |

### 2.2 收入五型（自我决定理论 + 心理账户 + 控制点）

| 类型 | 心理驱动 | 控制点 |
|------|---------|--------|
| 劳动收入 | 胜任感 | 内控 |
| 增值收入 | 远期规划 | 内控 |
| 馈赠收入 | 关系联结 | 外控 |
| 惊喜收入 | 意外之财 | 外控 |
| 回流收入 | 损失挽回 | 外控 |

### 2.3 欲望管理理论

| 机制 | 理论基础 |
|------|---------|
| 心愿 × 星光 | 延迟满足（Mischel）+ 执行意图（Gollwitzer） |
| 冷却机制 | 自我控制资源模型 + 冲动衰减曲线 |
| 亏空优先 | 心理账户负债厌恶 |

## 3. 系统架构

### 3.1 架构图

```
┌─────────────────────────────────────────────────┐
│                   Browser                       │
│  ┌──────────┐  ┌─────────────────────────────┐  │
│  │ React SPA│  │        IndexedDB (Dexie)     │  │
│  │          │◄─┤  transactions/categories/... │  │
│  │ Zustand  │  └─────────────────────────────┘  │
│  │ Recharts │                                    │
│  └────┬─────┘                                    │
│       │ API Call                                  │
│  ┌────▼─────────────────────────────────────┐   │
│  │  OpenAI SDK → DeepSeek API (可配置)        │   │
│  │  百度 REST API → 语音识别                   │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
         │
    GitHub Pages (静态托管)
```

### 3.2 数据流

```
用户操作 → React State → Dexie hooks(useLiveQuery)
  → IndexedDB 自动持久化
  → UI 自动响应更新
```

### 3.3 AI 辅助流程

**记账流程**：自由文本 → AI 解析(五型分类+金额+心情) → 用户确认 → 写入 DB

**冷却流程**：自由描述 → AI 分析(冲动类型+风险+建议冷却) → 用户选择冷却期 → 冷却中 → 到期评估 → 守住/释怀/再冷却

## 4. 页面设计

### 4.1 首页 Dashboard

```
┌──────────────────────────────────────┐
│  分账单切换 · 月份选择                │
├──────────────────────────────────────┤
│  🎭 心情 Banner（问候+心情图标+语录）│
├──────┬──────┬──────┬────────────────┤
│ 收入  │ 支出  │ 结余  │ 预算(进度环)    │ → 统计卡
├──────┴──────┴──────┴────────────────┤
│  五型消费扇形图  │ 心情×消费柱状图    │ → 图表行
├──────────────────────────────────────┤
│  30日收支趋势（面积图）              │ → 趋势
├──────────────────────────────────────┤
│  心情时间线 · 月历热力图              │ → 时间
├──────────────────────────────────────┤
│  筛选栏 · 交易列表                    │ → 数据
└──────────────────────────────────────┘
```

### 4.2 AI 助手

| Tab | 布局 |
|-----|------|
| 财务报告 | 四统计卡 → 双图表(扇形+柱状) → 预算进度 → 生成按钮 → 报告 |
| 心理分析 | 心情柱状图 → 心情一览列表 → 生成按钮 → 分析结果 |
| 对话助手 | 数据概览条 → 聊天区 → 输入框 |

### 4.3 心愿页

| Tab | 内容 |
|-----|------|
| 心愿 | 目标卡片 + StarJar 星光可视化 + 创建心愿 |
| 冷却 | 冷却中列表(环形倒计时) + 待确认列表(呼吸边框) + 记录冲动表单 |
| 轨迹 | 守住率/金额/星光统计 + 事件时间线 |

### 4.4 设置页

6 个 Section：API 配置 · 语音识别 · 主题配色 · 收支分类 · 月度预算 · 分账单 · 数据管理

## 5. 视觉设计

### 5.1 色彩

- **品牌色**：暖琥珀 `#d97706`（默认），6 种固定主题可选
- **卡片色阶**：5 级（accent / stat / chart / list / soft）
- **数据色**：收入绿、结余跟随主题、支出不着色（避免负罪感）

### 5.2 字体

- 字体栈：Inter → system-ui → sans-serif
- 金额：tabular-nums 等宽数字
- 层级：H1(1.5rem) → H2(1.25rem) → H3(0.9375rem) → Body(0.875rem)

### 5.3 动画

- 页面进入：slideUp 400ms
- 弹窗：popIn 250ms 弹性曲线
- 封面：图标物理漂浮 + 粒子网络
- 装饰：呼吸边框、浮动星光、极光背景
