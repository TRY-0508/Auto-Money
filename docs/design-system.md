# 心情收支簿 — 设计系统

> 温和、有陪伴感的消费心理工具。设计目标：让用户感到被理解而非被审判。

---

## 1. 设计原则

| 原则 | 含义 | 落地 |
|------|------|------|
| **温和** | 不审判、不施压 | 暖色调、柔和圆角、正面措辞 |
| **清晰** | 信息层次分明 | 大小写、粗细、间距形成自然层级 |
| **有层次** | 功能区用底色区分 | 五级卡片色阶 |
| **丰富** | 图表替代文字，不堆砌 | 扇形/柱状/面积图各有分工 |
| **始终如一** | 同一语义同一颜色 | 收入=绿、危险=红、主题=随全局 |

## 2. 色彩系统

### 2.1 主题色（6 种固定 + 8 种动态）

| 固定主题 | 主色 | 氛围 |
|---------|------|------|
| 暖琥珀 | `#d97706` | 温柔陪伴（默认） |
| 森绿 | `#059669` | 清新自然 |
| 海蓝 | `#2563eb` | 冷静理性 |
| 玫瑰粉 | `#e11d48` | 柔和温暖 |
| 薰衣草 | `#7c3aed` | 梦幻想象 |
| 日落橙 | `#ea580c` | 活力热情 |

动态心情模式：主题色跟随当月/当日心情自动切换。

### 2.2 语义色

| 语义 | 色值 | 使用限制 |
|------|------|---------|
| 收入 | `#10b981` | 仅金额展示 |
| 警示 | `#ef4444` | 仅需注意的操作 |
| 支出 | 正文色+粗体 | 不与红色绑定 |

### 2.3 卡片色阶

| 类名 | 用途 | 视觉重量 |
|------|------|---------|
| `.card-accent` | 品牌强调 | 最轻（主题微底） |
| `.card-stat` | 统计数字 | 中等 |
| `.card-chart` | 图表容器 | 较重（更不透明） |
| `.card-list` | 列表/时间线 | 较轻 |
| `.card-soft` | 空状态/装饰 | 最轻 |

所有卡片色阶通过 CSS 变量驱动，切换主题时自动变化。

'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif

## 4. 组件规范

### 4.1 按钮

| 类型 | 类名 | 场景 |
|------|------|------|
| 主按钮 | `.btn-primary` | 页面主操作 |
| 次按钮 | `.btn-secondary` | 取消/返回 |
| 危险按钮 | `.btn-danger` | 删除 |
| 图标按钮 | `.btn-icon` | 卡片内小操作 |

### 4.2 图表

| 场景 | 形式 | 配色 |
|------|------|------|
| 五型消费 | Donut 环形图 | 12 色循环 |
| 心情×消费 | 横向柱状图 | 8 种情绪色 |
| 收支趋势 | 面积图 | 绿/红半透明渐变 |
| 预算进度 | 水平进度条 | 绿→黄→红 |

### 4.3 进度指示

| 场景 | 形式 |
|------|------|
| 心愿进度 | SVG 环形进度环 |
| 冷却倒计时 | 小环形环（蓝→橙→红） |
| 预算进度 | 水平条（绿→黄→红） |
| AI 加载 | 图标脉冲 |

## 5. 动画

| 动画 | 触发 | 时长 | 缓动 |
|------|------|------|------|
| slideUp | 页面进入 | 400ms | cubic-bezier |
| bounceIn | 重要元素 | 550ms | elastic |
| popIn | 弹窗 | 250ms | elastic |
| breathe | 待确认事件 | 2.5s | 循环 |
| float | 图标/星光 | 3-4.5s | 循环 |

## 6. 背景特效

- **粒子网络**：Canvas 80 颗粒子 + 连线
- **极光背景**：3 个径向渐变椭圆，主题色驱动
- **浮动光球**：2 个大光球缓慢移动
