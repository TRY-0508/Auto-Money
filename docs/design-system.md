# 心情收支簿 — 设计系统

> 一个温和、有陪伴感的消费心理工具。设计目标是让用户在使用时感到被理解和被守护，而非被审判或被说教。

---

## 1. 产品定位与设计哲学

### 1.1 我们是什么

心情收支簿是一个 **AI 驱动的消费心理工具**，帮助用户：
- **看见**自己的消费模式和情绪关联
- **暂停**冲动，给自己冷静的空间
- **清醒选择**，而非被欲望裹挟

### 1.2 我们不是什么

- 不是冷冰冰的财务软件
- 不是说教式的省钱工具
- 不是游戏化的任务清单

### 1.3 设计原则

| 原则 | 含义 | 落地 |
|---|---|---|
| **温和** | 不审判、不施压，像朋友聊天 | 暖色调、柔和圆角、正面措辞 |
| **清晰** | 信息层次分明，一眼看懂 | 大小写、粗细、间距形成自然层级 |
| **克制** | 每个页面只有一个视觉焦点 | 不堆砌颜色、不滥用动画 |
| **有记忆点** | 封面和背景动画让人记住 | 粒子网络、浮动图标、环形进度 |
| **始终如一** | 同一语义用同一颜色 | 金额都是一种强调方式，不因场景变色 |

## 2. 色彩系统

### 2.1 设计理念

**主色提供品牌识别，辅助色提供信息层级，中性色承载大部分内容。**

同一卡片内不超过 **2 种语义色**。颜色用来**区分信息类型**，不是用来装饰。

### 2.2 色板

#### 主色 — 暖琥珀（品牌识别）

| Token | 色值 | 用途 |
|---|---|---|
| Primary | `#d97706` | 主按钮、激活态、重要强调 |
| Primary hover | `#b45309` | 按钮悬浮 |
| Primary soft | `rgba(217,119,6,0.08)` | 焦点环、柔和背景 |

#### 语义色 — 信息分层

| 语义 | 色值 | 用途 | 使用限制 |
|---|---|---|---|
| 收入/成功 | `#10b981` (emerald) | 收入金额 | 仅 Dashboard 金额展示 |
| 支出 | 不单独着色 | 支出金额用正文色 + 粗体 | 刻意不与红色绑定，避免负罪感 |
| 警示/危险 | `#ef4444` (red) | 删除按钮、风险标签、负结余 | **仅用于需要用户注意的操作** |
| 信息/分析 | `#3b82f6` (blue) | 必要性评估、链接 | 低频使用 |
| 辅助强调 | `#0d9488` (teal) | AI 建议冷却周期 | 与琥珀区分信息类型 |

#### 中性色 — 内容承载

| Token | 色值 | 用途 |
|---|---|---|
| 标题 | `#292524` (warm-900) | 所有标题 |
| 正文 | `#44403c` (warm-700) | 主要文字 |
| 次要 | `#78716c` (warm-500) | 辅助说明 |
| 弱化 | `#a8a29e` (warm-400) | 占位符、禁用态 |

#### 表面色

| Token | 说明 |
|---|---|
| 页面背景 | `linear-gradient(160deg, #fefcf8, #fef7ed, #fef9f0)` — 暖奶油渐变 |
| 卡片 | `rgba(255,255,255,0.65)` + `backdrop-blur(24px)` — 毛玻璃 |
| 暗色背景 | `linear-gradient(160deg, #1c1917, #191510, #1a1612)` — 暖棕暗调 |

### 2.3 颜色使用规则

**同一卡片内最多 2 种语义色。** 如果一个卡片里同时出现红、绿、蓝三种颜色的文字，说明信息层级没做好。

**金额默认不着色。** 支出不等于「坏事」，红色会让用户产生负罪感。只有**负结余**这种真正需要留意的场景才用红色。

**琥珀主色控制出现频率。** 同一视图内，琥珀只出现在：一个主按钮 + 一个激活 Tab + 至多一个强调数值。其他元素用中性色。

## 3. 字体系统

### 3.1 字体栈

```
'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
```

### 3.2 层级

| 层级 | 类名 | 大小 | 粗细 | 用途 |
|---|---|---|---|---|
| H1 | `.h1` | 1.5rem | 700 | 页面大标题 |
| H2 | `.h2` | 1.25rem | 700 | 区块标题、弹窗标题 |
| H3 | `.h3` | 0.9375rem | 600 | 卡片标题 |
| Body | 默认 | 0.875rem | 400 | 正文、列表 |
| Caption | `.text-xs` | 0.75rem | 400 | 辅助说明 |
| Amount | `.amount` | 继承 | 600 | 金额数字（tabalar-nums） |

### 3.3 规则

- 同一页面不超过 3 级标题
- 金额数字使用 `font-variant-numeric: tabular-nums` 保证对齐
- 字间距 `-0.01em` 全局，让中文和数字更紧凑
- 行高 `1.5`，段落间距用 `space-y-*` 控制

## 4. 组件规范

### 4.1 卡片（.card）

```
背景: rgba(255,255,255,0.7) + backdrop-blur(24px)
边框: 1px solid rgba(255,255,255,0.6)
圆角: 1.5rem
阴影: 0 2px 6px rgba(0,0,0,0.04), 0 8px 24px rgba(0,0,0,0.06)
```

- 所有内容容器使用 `.card`
- 卡片内部信息密度要低，留白充足
- 不同卡片之间用 `space-y-4`（16px 间距）

### 4.2 按钮

| 类型 | 类名 | 使用场景 |
|---|---|---|
| 主按钮 | `.btn .btn-primary` | 页面唯一主操作 |
| 次按钮 | `.btn .btn-secondary` | 取消、返回 |
| 危险按钮 | `.btn .btn-danger` | 删除 |
| 图标按钮 | `.btn-icon` | 卡片内小操作 |
| 小按钮 | `.btn-sm` | 列表项内 |

- 同一区域内**一个主按钮**，其他用次级
- 按钮禁用态统一 `opacity: 0.4`

### 4.3 输入框

```
背景: var(--s-input)
边框: 1px solid rgba(0,0,0,0.08)
圆角: 0.875rem
焦点: border-color: var(--c-primary) + 3px 柔和光晕
```

- Placeholder 用简洁提示，**不加举例**（「目标名称」而非「目标名称，如：买Switch」）

### 4.4 弹窗（Modal / Popup）

- 毛玻璃背景 + `backdrop-blur-2xl`
- 弹出动画：`scale(0.85)→scale(1)` + `opacity 0→1`，250ms 弹性曲线
- 点击遮罩或 ESC 关闭
- 弹窗内信息不超过 4 个逻辑块

### 4.5 进度指示

| 场景 | 形式 |
|---|---|
| 心愿金进度 | SVG 环形进度环（donut chart） |
| 冷却倒计时 | 小环形倒计时环（蓝→橙→红） |
| 金额进度条 | 水平渐变条（amber→yellow） |
| AI 加载 | 图标脉冲动画 |

### 4.6 Tab 切换

- 圆角药丸式容器，内部等分按钮
- 激活态：白底 + 微阴影 + 暖琥珀文字
- 切换内容区带淡入动画（`fadeSlide` 250ms）

## 5. 动画规范

### 5.1 设计理念

动画服务于**信息传递**，而非装饰。每个动画都要有明确的触发时机和功能。

### 5.2 动画清单

| 动画 | 触发 | 时长 | 缓动 | 用途 |
|---|---|---|---|---|
| slideUp | 页面进入 | 400ms | cubic-bezier(0.16,1,0.3,1) | 内容从下方滑入 |
| fadeSlide | Tab 切换 | 250ms | ease-out | 内容淡入上移 |
| bounceIn | 重要元素出现 | 550ms | cubic-bezier(0.68,-0.55,0.27,1.55) | 封面图标、目标达成 |
| popIn | 弹窗打开 | 250ms | cubic-bezier(0.34,1.56,0.64,1) | 弹窗弹性缩放入场 |
| breathe | 待确认事件 | 2500ms | ease-in-out 循环 | 呼吸边框吸引注意 |
| float | 图标/星光 | 3-3.5s | ease-in-out 循环 | 柔和浮动 |
| starFloat | 星光 | 3-4.5s | ease-in-out 循环 | 星光有机浮动 |
| ring fill | 进度环 | 700-1000ms | ease-out | 环形进度填充 |

### 5.3 规则

- 同一视图内同时播放的动画不超过 3 种
- 无限循环动画仅用于背景/装饰元素（粒子、星光浮动）
- 功能性动画（进度填充、倒计时）每次触发一次，不循环

## 6. 背景特效

### 6.1 粒子网络（ParticleNetwork）

- Canvas 绘制 80 个暖杏色粒子
- 粒子间距离 < 120px 时绘制半透明连线
- 粒子缓速移动 + 边缘回弹
- 始终在 `z-index: 1`，不干扰交互

### 6.2 点击粒子爆炸（ParticleEffect）

- 非交互元素点击时触发
- 8 个彩色粒子向四周扩散 + 缩小消失
- 色彩：暖金、橙、粉、青绿、绿、红 — 温暖但不刺眼
- 600ms 后自动清理

### 6.3 极光背景（Aurora）

- 三个径向渐变椭圆叠加，缓慢呼吸动画
- 颜色：暖金、桃色、琥珀 — 低透明度，不抢内容

### 6.4 浮动光球（Orbs）

- 两个大光球在页面背景缓慢移动
- 颜色：金、橙 — blur 80px，opacity 0.3

## 7. 页面布局

### 7.1 通用布局

- 桌面端：左侧固定侧栏（256px）+ 右侧内容区
- 移动端：顶部标题栏 + 底部导航栏 + 中间内容
- 内容最大宽度 `max-w-lg`（512px），居中
- 底部留白 `pb-24`（移动端底部导航高度）

### 7.2 Dashboard（Bento 网格）

4 列网格（移动端 2 列），卡片 `span` 控制宽度

### 7.3 心愿页（JarPage）

3 Tab 布局，Tab 栏固定在内容顶部

### 7.4 AI 助手

3 Tab 布局，内容区可滚动

## 8. 文案规范

### 8.1 语气

- 温和、正面、不评判
- 用「守住」替代「克制」，用「释怀」替代「失败」
- 用「心愿」替代「目标」，用「星光」替代「积分」

### 8.2 占位符

- 简洁直接，不举例
- 好：「目标名称」/ 不好：「目标名称，如：买Switch」
- 好：「描述你想买的东西和原因」/ 不好：「想买什么？如：一双限量球鞋」

### 8.3 按钮文案

- 动词为主，2-4 字
- 「守住它」「还是想要」「去看看」「开始冷却」

---

## 9. 数据展示规范

### 9.1 金额

- 始终使用 `formatAmount()` 统一格式化
- 金额数字不单独着色（除非负结余等警示场景）
- 使用 `tabular-nums` 保证数字对齐

### 9.2 百分比

- 圆环进度：金额在中心，百分比在下方
- 进度条：百分比在右侧

### 9.3 列表

- 事件列表用卡片分隔
- 时间线按时间倒序
- 空状态显示浮动图标 + 引导文字

## 附录：常见错误

| 错误 | 正确做法 |
|---|---|
| 一个卡片内红绿蓝三种文字色 | 最多 2 种语义色，其余用正文色 |
| 所有内容都用琥珀色强调 | 琥珀仅用于主操作和关键信息 |
| Placeholder 里写「如：XXX」 | 直接用简短字段名 |
| 按钮颜色和文本颜色混用同一色值 | 按钮用渐变，文本用纯色 |
