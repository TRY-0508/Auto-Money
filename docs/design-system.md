# 心情收支簿 — 设计系统

> 一个温和、有陪伴感的消费心理工具。设计目标是让用户在使用时感到被理解和被守护，而非被审判或被说教。

---

## 1. 产品定位与设计哲学

### 1.1 我们是什么

心情收支簿是一个 **AI 驱动的消费心理工具**，帮助用户：
- **看见**自己的消费模式和情绪关联
- **暂停**冲动，给自己冷静的空间
- **清醒选择**，而非被欲望裹挟

### 1.2 我们不是什么

- 不是冷冰冰的财务软件
- 不是说教式的省钱工具
- 不是游戏化的任务清单

### 1.3 设计原则

| 原则 | 含义 | 落地 |
|---|---|---|
| **温和** | 不审判、不施压，像朋友聊天 | 暖色调、柔和圆角、正面措辞 |
| **清晰** | 信息层次分明，一眼看懂 | 大小写、粗细、间距形成自然层级 |
| **克制** | 每个页面只有一个视觉焦点 | 不堆砌颜色、不滥用动画 |
| **有层次** | 卡片间用底色区分功能区 | 五级卡片色阶系统 |
| **丰富但不繁杂** | 图表替代文字，但不堆砌 | 扇形图、柱状图、面积图、时间线各有分工 |
| **有记忆点** | 封面和背景动画让人记住 | 粒子网络、浮动图标、环形进度 |
| **始终如一** | 同一语义用同一颜色 | 金额都是一种强调方式，不因场景变色 |

## 2. 色彩系统

### 2.1 设计理念

**主色提供品牌识别，辅助色提供信息层级，中性色承载大部分内容。**

同一卡片内不超过 **2 种语义色**。颜色用来**区分信息类型**，不是用来装饰。

### 2.2 色板

#### 主色 — 暖琥珀（品牌识别）

| Token | 色值 | 用途 |
|---|---|---|
| Primary | `#d97706` | 主按钮、激活态、重要强调 |
| Primary hover | `#b45309` | 按钮悬浮 |
| Primary soft | `rgba(217,119,6,0.08)` | 焦点环、柔和背景 |

#### 心理五型消费色

| 类型 | 色值 | 图标 |
|---|---|---|
| 必要消费 | `#3b82f6` 蓝 | `home` |
| 价值消费 | `#10b981` 绿 | `trending-up` |
| 情绪消费 | `#f43f5e` 红 | `heart` |
| 冲动消费 | `#f59e0b` 琥珀 | `zap` |
| 意外消费 | `#f97316` 橙 | `alert-triangle` |

#### 语义色 — 信息分层

| 语义 | 色值 | 用途 | 使用限制 |
|---|---|---|---|
| 收入/成功 | `#10b981` (emerald) | 收入金额、盈余 | 仅 Dashboard 金额展示 |
| 支出 | 不单独着色 | 支出金额用正文色 + 粗体 | 刻意不与红色绑定，避免负罪感 |
| 警示/危险 | `#ef4444` (red) | 删除按钮、风险标签、负结余 | **仅用于需要用户注意的操作** |
| 预算 | `#a855f7` (purple) | 预算卡片 | 预算专属色 |
| 信息/分析 | `#3b82f6` (blue) | 必要性评估、链接 | 低频使用 |
| 辅助强调 | `#0d9488` (teal) | AI 建议冷却周期 | 与琥珀区分信息类型 |

#### 中性色 — 内容承载

| Token | 色值 | 用途 |
|---|---|---|
| 标题 | `#292524` (warm-900) | 所有标题 |
| 正文 | `#44403c` (warm-700) | 主要文字 |
| 次要 | `#78716c` (warm-500) | 辅助说明 |
| 弱化 | `#a8a29e` (warm-400) | 占位符、禁用态 |

#### 表面色

| Token | 说明 |
|---|---|
| 页面背景 | `linear-gradient(160deg, #fefcf8, #fef7ed, #fef9f0)` — 暖奶油渐变 |
| 统计卡 | `rgba(255,255,255,0.72)` — 半透明白底 |
| 图表卡 | `rgba(255,255,255,0.88)` — 更不透明白底 |
| 列表卡 | `rgba(250,249,247,0.6)` — 极淡灰底 |
| 品牌卡 | `rgba(245,158,11,0.06)` — 琥珀极浅底 |
| 柔和卡 | `rgba(255,255,255,0.45)` — 最透明底 |
| 暗色背景 | `linear-gradient(160deg, #1c1917, #191510, #1a1612)` — 暖棕暗调 |

### 2.3 卡片色阶系统

| 类名 | 用途 | 视觉重量 |
|---|---|---|
| `.card-stat` | 统计数字卡片 | 中等 |
| `.card-chart` | 图表卡片 | 较重（更不透明） |
| `.card-list` | 列表/时间线 | 较轻 |
| `.card-accent` | 品牌强调卡片 | 最轻（琥珀底色） |
| `.card-soft` | 柔和装饰卡片 | 最轻 |

### 2.4 颜色使用规则

**同一卡片内最多 2 种语义色。**

**金额默认不着色。** 支出不等于「坏事」。

**琥珀主色控制出现频率。** 同一视图内，琥珀只出现在：一个主按钮 + 一个激活 Tab + 至多一个强调数值。

**卡片底色差异化**：相邻卡片用不同色阶，制造可感知但不刺眼的色彩差异。

| Amount | `.amount` | 继承 | 600 | 金额数字（tabalar-nums） |

## 4. 组件规范

### 4.1 卡片（.card）

基础卡片毛玻璃效果。按功能角色选择对应色阶类。

### 4.2 按钮、输入框

保持不变。

### 4.3 图表

| 场景 | 形式 | 配色 |
|---|---|---|
| 五型消费分布 | Donut 环形图 | 五色（蓝/绿/红/琥珀/橙） |
| 心情×消费 | 横向柱状图 | 8种情绪色 |
| 收支趋势 | 面积图 | 绿（收入）/ 红（支出）半透明渐变 |
| 预算进度 | 水平条形 + 百分比 | 绿→黄→红渐变 |
| 月历热力图 | 日格 | 灰→黄→橙→红四级 |

### 4.4 进度指示

| 场景 | 形式 |
|---|---|
| 心愿金进度 | SVG 环形进度环（donut chart） |
| 冷却倒计时 | 小环形倒计时环（蓝→橙→红） |
| 预算进度 | 水平条形（emerald→amber→red） |
| AI 加载 | 图标脉冲动画 |

## 7. 页面布局

### 7.1 Dashboard（Bento Grid + 卡片色阶）

```
心情 Banner（品牌卡底色）
四统计卡片（.card-stat）
双图表行（.card-chart）
趋势图（.card-chart）
时间线（.card-list）
月历（.card-chart）
交易列表（.card-list）
```

### 7.2 AI 助手

三 Tab 布局，每个 Tab 内独立卡片化：
- 财务报告：统计卡 + 图表卡 + 品牌卡（预算进度）+ 报告卡
- 心理分析：图表卡 + 列表卡 + 分析结果卡
- 对话：数据条 + 消息区 + 输入框

## 9. 配色方案设置

设置页提供 4 种配色策略选择：
| 策略 | 说明 |
|---|---|
| 最多心情 | 跟随本月频次最高的心情 |
| 最新消费 | 跟随最近一笔消费的心情 |
| 中性色调 | 始终使用暖奶油色 |
| 全天适应 | 根据当日心情动态变化 |

## 附录：常见错误

| 错误 | 正确做法 |
|---|---|
| 所有卡片用同一底色 | 使用卡片色阶系统区分功能区 |
| 一个卡片内红绿蓝三种文字色 | 最多 2 种语义色，其余用正文色 |
| 所有内容都用琥珀色强调 | 琥珀仅用于主操作和关键信息 |
| 图表配色刺眼生硬 | 使用半透明柔和色 + 圆角 |
