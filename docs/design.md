# 心情收支簿 — 系统设计

> 面向开发者的完整设计文档：架构、数据、页面、组件、视觉规范。

## 1. 产品定位

AI 驱动的消费心理学工具。帮助用户**看见消费心理模式、暂停冲动、清醒选择**。

核心隐喻：每次守住冲动 = 一束**星光** → 积累成长。

## 2. 心理学理论体系

### 2.1 消费五型（Kahneman 双系统 + Dittmar 消费文化）

| 类型 | 驱动 | 说明 |
|------|------|------|
| 必要消费 | System 2 | 维持基本生存运转 |
| 价值消费 | System 2 | 对齐长期目标、自我成长 |
| 情绪消费 | System 1 | 情绪状态的消费投射 |
| 冲动消费 | System 1 | 无计划即时决策 |
| 意外消费 | 外部事件 | 突发不可控支出 |

### 2.2 收入分类

收入使用传统务实分类：工资、兼职、理财、红包、其他。

### 2.3 欲望管理

| 机制 | 理论基础 |
|------|---------|
| 心愿 × 星光 | 延迟满足（Mischel） |
| 冲动冷却 | 自我控制资源模型 |
| 预算管控 | 心理账户理论 |

## 4. 数据模型

### 4.1 交易 Transaction
`type`: expense | income · `amount`, `categoryId`, `date`, `description`, `mood`

### 4.2 分类 Category
- 支出：必要消费、价值消费、情绪消费、冲动消费、意外消费
- 收入：工资、兼职、理财、红包、其他
- 用户可创建自定义分类

### 4.3 预算 Budget
月度消费上限，每月可设定。超支形成亏空需填平。

### 4.4 心愿 JarGoal
`name`, `targetAmount`, `currentAmount`, `color`
金额来自：抵御冲动金额 + 预算结余转入

### 4.5 冷却事件 CoolDownEvent
```
新建 → cooling → pending_review
                    ├── resisted（守住 → 星光+金额计入心愿）
                    └── failed（释怀/购买/再冷却）
```
支持提前守住（冷却中即可确认）。

### 4.6 设置 Settings
API 配置、语音、主题配色、暗色模式、全局星光计数器

## 5. 主题系统

- **动态心情**：3 策略（最多心情/最新消费/全天适应），主题色跟随心情
- **固定配色**：6 预设（暖琥珀/森绿/海蓝/玫瑰粉/薰衣草/日落橙）
- 覆盖：页面背景、5 级卡片色阶、按钮渐变、文字强调、极光背景
- CSS 变量架构：`:root` → `.theme-*` → `.theme-dynamic-*` → `.dark`
