# 心情收支簿 — 系统设计

## 1. 页面架构

| 路由 | 页面 | 功能 |
|---|---|---|
| `/` | Dashboard | 心情 Banner + 四统计卡片 + 五型扇形图 + 心情柱状图 + 30日面积图 + 时间线 + 月历 + 交易列表 |
| `/ai` | AI 助手 | 3 Tab：财务报告 / 心理分析 / 对话 |
| `/jar` | 心愿 | 3 Tab：心愿 / 冷却 / 成长轨迹 |
| `/settings` | 设置 | API · 语音 · 主题 · 分类 · 预算 · 分账单 · 数据 |
| `[Modal]` | 记账弹窗 | 文字 AI / 语音 / 手动（五型分类 + 心情 + 模板） |
| `[Splash]` | 封面页 | 物理浮动图标 + 粒子动画 |

## 2. 数据模型

### 2.1 交易（Transaction）
- 类型：expense / income
- 金额、分类、日期、描述、心情、分账单归属

### 2.2 分类（Category）
- **支出 5 型**：必要消费、价值消费、情绪消费、冲动消费、意外消费
- **收入 5 型**：劳动收入、增值收入、馈赠收入、惊喜收入、回流收入
- 用户可创建自定义分类

### 2.3 预算（Budget）
- 月度总预算 + 分类子预算
- 进度跟踪：已用百分比 + 剩余金额
- 盈余自动转入心愿，亏空优先填平

### 2.4 亏空（Deficit）
- 月度超支记录
- 星光优先填平亏空，之后才能积攒心愿

### 2.5 心愿（JarGoal）
- 目标名称、金额、进度、星光数
- 守住冲动 → 星光 + 金额增加

### 2.6 冷却事件（CoolDownEvent）
```
(新建) → cooling → pending_review
                       ├── resisted（守住 → 星光+金额）
                       └── failed（释怀/购买/再冷却）
```
冷却时间：6h / 12h / 1天 / 2天 / 3天 / 7天

### 2.7 设置（Settings）
- API 配置、语音、主题配色、暗色模式、分类、预算

## 3. AI 辅助流程

### 记账
```
自由文本 → AI 解析(五型+金额+心情) → 用户确认 → 写入 DB
```

### 冲动冷却
```
自由描述 → AI 分析(类型+风险+冷却建议) → 用户选择冷却期 → 倒计时 → 重评估
```

### 报告/分析
```
月度数据 + 心情关联 → AI 生成报告/分析 → Markdown 渲染
```

## 4. 主题系统

### 配色模式
- **动态心情**：3 种策略（最多心情 / 最新消费 / 全天适应）
- **固定配色**：6 种预设（暖琥珀 / 森绿 / 海蓝 / 玫瑰粉 / 薰衣草 / 日落橙）

### 覆盖范围
页面背景、卡片底色（5 级色阶）、按钮渐变、文字强调色、极光背景

## 5. 数据库

Schema v7 · IndexedDB · Dexie.js · 9 个表 · 支持升级迁移
