# 心情收支簿 — 系统设计

## 1. 页面架构

| 路由 | 页面 | 功能 |
|---|---|---|
| `/` | Dashboard | 心情 Banner + 四统计卡片（收入/支出/结余/预算）+ 五型扇形图 + 心情柱状图 + 30日趋势折线图 + 心情时间线 + 月历热力图 + 交易列表 |
| `/ai` | AI 助手 | 3 Tab：财务报告（卡片+图表） / 心理分析（柱状图+一览） / 对话（数据条+聊天） |
| `/jar` | 心愿 | 3 Tab：心愿目标（含亏空状态） / 欲望冷却（手动调整冷却期） / 成长轨迹 |
| `/settings` | 设置 | API · 语音 · 配色方案 · 分类 · 预算 · 分账单 · 数据 |
| `[Modal]` | 记账弹窗 | 文字 AI / 语音按住 / 手动表单（五型分类 + 心情 + 模板） |
| `[Splash]` | 封面页 | 首次/会话打开展示，浮动图标动画 |

## 2. 命名规范

| 概念 | 命名 | 动词/状态 |
|---|---|---|
| 长期储蓄目标 | **心愿** | 创建心愿、心愿达成 |
| 成功面对冲动 | **守住** | 守住冲动 |
| 获得标记 | **星光** | 收获星光 |
| 冷静后放弃购买 | **守住** | 已守住 |
| 冷静后仍想买 | **释怀** | 已释怀 / 已购买 |
| 冷静中 | **冷却中** | 冷却中 |
| 重评估 | **去看看** | 去看看 |
| 预算超出 | **亏空** | 亏空中 / 已填平 |

## 3. 数据模型

### 3.1 事务（Transaction）
不变，仍支持 8 种心情 + 五型消费分类 + 收入分类。

### 3.2 分类（Category）
- **支出**：必要消费、价值消费、情绪消费、冲动消费、意外消费（5 个系统预设）
- **收入**：工资、兼职、理财、红包、其他（5 个系统预设）
- 用户可自定义扩展

### 3.3 预算（Budget）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | UUID |
| categoryId | string \| null | null=总预算 |
| amount | number | 预算金额 |
| period | 'monthly' \| 'yearly' | 周期 |
| yearMonth | string | "2025-06" |

### 3.4 亏空（Deficit）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | UUID |
| amount | number | 亏空金额 |
| yearMonth | string | 产生月份 |
| remainingAmount | number | 剩余待填平 |
| status | 'active' \| 'filled' | 状态 |
| createdAt | number | 创建时间戳 |

### 3.5 设置（Settings）新增字段

| 字段 | 类型 | 说明 |
|---|---|---|
| colorScheme | 'most-frequent' \| 'latest' \| 'neutral' \| 'adaptive' | 配色策略 |

### 3.6 心愿（JarGoal）
不变。

### 3.7 冷却事件（CoolDownEvent）

**状态流转**：
```
(新建) → cooling → pending_review
                       ├── resisted（守住 → 获星光+金额计入心愿/填亏空）
                       └── failed
                              ├── purchased（释怀 → 标记已购买）
                              └── cooling（再次冷却）
```

冷却时间选项：6h / 12h / 1天 / 2天 / 3天 / 7天（用户可手动选择，默认AI建议→24h）

## 4. 配色方案

| 策略 | 行为 |
|---|---|
| `most-frequent` | 跟随本月出现最多的心情（默认） |
| `latest` | 跟随最近一笔消费的心情 |
| `neutral` | 始终使用暖奶油中性色 |
| `adaptive` | 根据当日心情全天动态变化 |

## 5. AI 辅助流程

### 欲望冷却创建时

```
用户自由描述（文本）
        ↓
AI 分析：消费类型 / 渴望度 / 必要性 / 风险因素 / 建议冷却 / 反思问题
        ↓
用户手动选择冷却时间（6h~7d）
        ↓
确认 → 开始冷却
```

### 冷却结束后重评估

```
展示原始记录 + AI 分析
        ↓
用户重评渴望程度 + 反思
        ↓
决定：守住 / 还是想要 / 再冷却
```

## 8. 视觉设计系统

### 卡片色阶（card color tiers）

| 类名 | 用途 | 底色 |
|---|---|---|
| `.card-stat` | 统计数字卡片 | 半透明白底 |
| `.card-chart` | 图表卡片 | 更不透明白底 |
| `.card-list` | 列表/时间线 | 极淡灰底 |
| `.card-accent` | 品牌强调卡片 | 琥珀极浅底 |
| `.card-soft` | 柔和装饰卡片 | 最透明底 |
| `.card` | 默认通用卡片 | 标准毛玻璃 |

### 图表规范
- **扇形图**（Donut）：五型消费分布，五色分区，中心留白
- **柱状图**（横向）：心情×消费金额，情绪色渐变
- **面积图**：30日收支趋势，半透明渐变填充
- **进度环**：预算消耗，绿→黄→红渐变
