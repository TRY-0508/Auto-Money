# 心情收支簿 — 项目概念

## 一句话描述

基于消费心理学理论的情绪化记账与自我觉察工具。

## 核心心理学理论

### 四型消费框架（基于 Kahneman 双系统 + Dittmar 消费文化理论）

Kahneman 提出人类决策有两套系统：**System 1**（快速、直觉、情绪化）和 **System 2**（缓慢、理性、分析性）。消费行为往往由 System 1 驱动，产生情绪化、冲动型支出。

结合 Dittmar 的消费文化理论（消费是身份建构和情绪调节的工具），我们将消费分为四类：

| 类型 | 系统驱动 | 特征 | 示例 |
|---|---|---|---|
| **必要消费** | System 2 | 维持生存和基本运转，几乎无情绪色彩 | 房租、水电、基础饮食 |
| **价值消费** | System 2 | 对齐长期目标和个人成长，带来满足感 | 课程、健身、书籍、体检 |
| **情绪消费** | System 1 驱动 | 由情绪状态触发，可能是正向庆祝或负向补偿 | 焦虑时暴食、开心时请客、难过时买衣服 |
| **冲动消费** | System 1 突发 | 无计划、即时决策，事后常后悔 | 深夜刷直播下单、凑满减买了一堆没用的 |

### 自我调节理论 + 积攒瓶

基于 **延迟满足（Mischel 棉花糖实验）** 和 **执行意图（Gollwitzer）**：设定"如果-那么"计划能显著提升目标达成率。

积攒瓶机制采用「**冷静事件 → 冷静期锁 → 重新评估**」三步流程：

1. **创建冷静事件**：用户面对冲动/情绪消费欲望时，记录购买冲动（描述、金额、渴望程度、必要性、情绪影响），并设定一个冷静周期（1h / 6h / 24h / 3d / 7d）
2. **冷静期等待**：事件进入「冷却中」状态，在此期间用户不能做任何操作（强制冷静），界面显示倒计时
3. **冷静后重评估**：冷静期到期后，用户重新评估自己的欲望。如果欲望已消退 → **克制成功**，获得一颗星星存入积攒瓶；如果依然想要 → 可选择「还是想买」（触发记账）或「再冷静一下」（自动延长冷静期）

#### 失败处理（冷静后依然想要）

冷静期并非为了阻止所有消费，而是过滤掉纯粹的冲动。如果一个欲望经过足够长的冷静期后依然强烈，可能说明这笔消费有其合理性。因此失败后的两种处理方式：

- **选择购买**：直接跳转记账界面，创建一笔对应的消费记录（自动归入冲动/情绪消费类型），该冷静事件标记为「已购买」
- **再次冷静**：将冷静期重置，尝试第二次克制

#### 星星与积攒瓶

- 每次克制成功获得 1 颗星星
- 星星累积进积攒瓶中，可视化长期克制的积累成果
- 每个积攒瓶绑定一个长期目标（如「攒钱买 Switch」），设定目标星星数
- 达到目标星星数时触发达成动画

## 核心功能

| 功能 | 说明 |
|---|---|
| **AI 记账** | 自然语言输入 → AI 自动提取金额、心情、四型分类、日期、描述 |
| **心情 × 消费可视化** | 彩虹比例条 + 心情胶囊 + 四型分布饼图 |
| **AI 心理分析** | 基于四型框架分析消费模式，给出心理学建议 |
| **消费积攒瓶** | 设定长期目标 → 犹豫消费触发冷静事件 → 冷静锁 → 到期重评估 → 克制成功得星星 → 瓶子满溢动画 |
| **冷静事件系统** | 多维度记录欲望（渴望度/必要性/情绪影响）→ 设置冷静周期 → 倒计时等待 → 重新评估 → 成功/失败分流 |
| **AI 对话** | 带心情 + 四型上下文，可追问消费心理学问题 |

## 不包含

云同步、多用户、银行对接、复杂投资理财
