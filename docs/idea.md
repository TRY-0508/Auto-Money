# Auto Money — 项目概念

## 一句话描述

AI 驱动、有人情味的个人收支管理助手，一个纯前端的网页应用。

## 项目方向

传统记账应用的最大痛点在于"输入太麻烦"——手动选择分类、填写金额、标注日期，用户往往坚持不了几天就放弃。Auto Money 把 AI 作为解决这个痛点的核心手段：用户只需用自然语言（文字或语音）描述一笔收支，AI 自动完成结构化录入。在此基础上，AI 还承担周期报告、对话查询、预算建议等角色，扮演一个真正有用的"财务小管家"。

## 可行性分析

| 维度 | 判断 | 说明 |
|---|---|---|
| 技术可行性 | 可行 | 纯前端 SPA + IndexedDB + 第三方 LLM API，无需自有服务器 |
| 部署可行性 | 可行 | GitHub Pages 静态托管，零运维成本 |
| 数据安全 | 可行 | 数据全在用户浏览器本地，API Key 由用户自行填入并本地保存，不上传任何服务端 |
| 用户体验 | 可行 | Web Speech API 支持主流浏览器语音输入，LLM 响应可控制在 2-3 秒内 |

## 核心优势

1. **零摩擦记账**：说句话就能记一笔账，不需要任何手动填表操作
2. **有人情味的 AI**：不是冷冰冰的数据报表，而是像一个朋友一样帮你分析、提醒、鼓励
3. **数据自主可控**：所有数据存在浏览器本地，不上传任何服务器
4. **零成本部署**：GitHub Pages 免费托管，用户只需要有自己的 LLM API Key

## 目标用户

- 想记账但坚持不下来的普通人
- 喜欢尝试 AI 工具的科技爱好者
- 对数据隐私有要求的用户

## 项目边界

### 包含

- 收支记录（增删改查）
- 文字/语音自然语言录入 + AI 结构化解析
- 分类管理（预设 + 自定义）
- 按日/周/月/年的时间筛选
- AI 周报/月报生成
- AI 对话查询（"这个月吃饭花了多少"）
- 预算设置与 AI 建议
- 数据导出（CSV/JSON）
- 多设备数据迁移（导出/导入）

### 不包含

- 多用户/账号体系
- 云端同步（依赖服务端，与 GitHub Pages 模式冲突）
- 银行账户对接
- 多人协作/家庭账本
- 复杂的投资/理财功能
