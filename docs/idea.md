# 心情收支簿 — 项目概念

## 一句话描述

基于消费心理学理论的智能记账与欲望管理工具。

## 核心理念

消费冲动的本质不是「需要克制」的负面行为，而是每个人都会经历的内心对话。
我们的角色不是审判者，而是帮你**看见欲望、暂停冲动、清醒选择**的陪伴者。

**核心隐喻**：每一次面对冲动时的清醒选择，都是一束**星光**。星光积累，点亮你真正想要抵达的**心愿**。

## 核心心理学理论

### 五型消费框架（基于 Kahneman 双系统 + Dittmar 消费文化理论）

Kahneman 提出人类决策有两套系统：**System 1**（快速、直觉、情绪化）和 **System 2**（缓慢、理性、分析性）。消费行为往往由 System 1 驱动，产生情绪化、冲动型支出。

结合 Dittmar 的消费文化理论（消费是身份建构和情绪调节的工具），我们将消费分为五类：

| 类型 | 系统驱动 | 特征 |
|---|---|---|
| **必要消费** | System 2 | 维持生存和基本运转，几乎无情绪色彩 |
| **价值消费** | System 2 | 对齐长期目标和个人成长，带来满足感 |
| **情绪消费** | System 1 驱动 | 由情绪状态触发，正向庆祝或负向补偿 |
| **冲动消费** | System 1 突发 | 无计划、即时决策，事后常后悔 |
| **意外消费** | — | 突发意外支出，如维修、医疗急症 |

### 五型收入框架（基于自我决定理论 + 心理账户 + 控制点理论）

收入并非只是数字的增长。**自我决定理论（Deci & Ryan）**认为，人类行为由三种基本心理需求驱动：**自主性**（我选择）、**胜任感**（我能行）、**关系联结**（我被爱）。同时，**心理账户理论（Thaler）**发现人们对不同来源的钱有不同的心理标签和消费倾向——辛苦挣来的钱被谨慎对待，意外之财则更随意。

结合 **控制点理论（Rotter）**——内控型（自己掌控结果）vs 外控型（外部力量决定），我们将收入分为五类：

| 类型 | 心理驱动 | 控制点 | 典型场景 |
|---|---|---|---|
| **劳动收入** | 胜任感 — 用技能和时间换回报 | 内控 | 工资、兼职、奖金、稿费 |
| **增值收入** | 远期规划 — 让资产为自己工作 | 内控 | 理财收益、利息、租金、分红 |
| **馈赠收入** | 关系联结 — 来自他人的情感性给予 | 外控 | 红包、礼物、父母资助、他人请客 |
| **惊喜收入** | 意外之财 — 不期而遇的幸运 | 外控 | 中奖、捡钱、退税、意外退款 |
| **回流收入** | 损失挽回 — 此前支出的反向流动 | 外控 | 报销、押金退还、退货退款 |

> **心理学意义**：理解收入来源的心理驱动，能帮我们看清自己与金钱的关系——你是靠能力在赚钱（劳动/增值），还是在依赖他人和运气（馈赠/惊喜）？这种觉察本身就是财务自我认知的第一步。

### 欲望管理：从「克制」到「驾驭」

传统记账工具教你「克制消费」，但单纯的压抑往往适得其反。我们的做法不同：

- **看见欲望**：记录冲动时不做评判，AI 帮助你客观分析
- **给自己时间**：设定冷却期（支持手动 6h~7d 选择），让冲动的热度自然消退
- **清醒选择**：冷静后再决定 —— 守住，或释怀。两种选择都没有错

### 心愿 × 星光机制

基于 **延迟满足（Mischel）** 和 **执行意图（Gollwitzer）**：

- **心愿**：你真正想达成的长期目标（一笔旅行基金、一件心仪已久的物品）
- **星光**：每次成功面对冲动后的奖励标记
- **积累**：星光汇聚，心愿渐近

### 预算 × 盈余/亏空机制

- **月度预算**：自主设定每月支出上限
- **盈余转入**：月末支出 < 预算时，差额可转入心愿积攒
- **亏空填平**：月末支出 > 预算时，差额形成亏空，后续星光需优先填平亏空

## 核心功能

| 功能 | 说明 |
|---|---|
| **AI 记账** | 自然语言输入 → AI 自动提取金额、心情、五型分类 |
| **心情 × 消费可视化** | 柱状图（各心情消费金额）+ 扇形图（五型分布）+ 折线图（30日趋势） |
| **AI 心理分析** | 基于五型框架分析消费模式，给出心理学建议 |
| **心愿管理** | 设定心愿目标金额 → 每次守住冲动累积星光和金额 → 进度可视化 |
| **欲望冷却** | AI 辅助分析 → 手动选择冷却期（6h~7d）→ 到期重评估 → 守住 / 释怀 |
| **月度预算** | 设定月度预算 → 进度环跟踪 → 盈余转入心愿 / 亏空优先填平 |
| **成长轨迹** | 守住率 + 守住金额 + 星光总数 + 事件时间线 |
| **AI 对话** | 带心情 + 五型上下文，可追问消费心理学问题 |
| **配色方案** | 支持四种策略：最多心情 / 最新消费 / 中性色调 / 全天适应 |

## 命名哲学

| 传统说法 | 我们的说法 | 理念 |
|---|---|---|
| 克制消费 | **守住** | 主动选择，非被动压抑 |
| 克制失败 | **释怀** | 有意识的放手，不是失败 |
| 积攒瓶 | **心愿** | 你在积累的是愿望，不是苦行 |
| 历史统计 | **成长轨迹** | 这是你的进化路线，不是成绩单 |
| 超预算 | **亏空** | 可以承认、需要填平，不是罪恶 |

## 不包含

云同步、多用户、银行对接、复杂投资理财
