# 心情收支簿 — 项目概念

## 一句话描述

记录金钱与心情，用 AI 洞察消费背后的情绪密码。一门消费心理学课的演示项目。

## 项目缘起

传统记账软件关心"钱去哪了"，但从不关心"为什么花"。行为经济学和消费心理学告诉我们：每一次消费决策背后都有情绪驱动——焦虑时报复性购物、开心时犒劳自己、疲惫时用外卖替代做饭。

**心情收支簿**把"心情"从背景噪音提升为第一等数据。用户在记录每一笔收支的同时，花 1 秒选择一个心情 emoji。系统通过关联分析，帮你看见原本隐形的模式：原来你每个周三下午最焦虑，而且这时外卖支出最高；原来你买游戏最开心，但买完衣服反而更焦虑。

## 目标用户与场景

| 用户 | 场景 |
|---|---|
| 心理学课堂讲师/学生 | 演示情绪-消费行为的关联，作为课堂案例 |
| 对自我觉察感兴趣的普通人 | 想知道"我的消费习惯和情绪有什么关系" |
| 被情绪性消费困扰的人 | 想减少焦虑/难过驱动的冲动消费 |

## 核心功能优先级

### Tier 1 — 核心（必须完整）

| 功能 | 心理学意义 |
|---|---|
| **记账+心情录入** | 数据采集入口，心情与消费绑定 |
| **心情×消费可视化** | 直观展示情绪-金额-分类的关联 |
| **AI 心理分析报告** | 用自然语言解读数据，给出心理学建议 |
| **AI 对话助手** | 可追问具体问题，带心情上下文 |

### Tier 2 — 支撑（保留但精简）

| 功能 | 说明 |
|---|---|
| 分类管理 | 预设+自定义，保留作为分析维度之一 |
| 分账单(Project) | 用于追踪特定主题（如"旅行"），移到设置页 |
| AI 文字/语音记账 | 降低录入摩擦 |
| 快速模板 | 历史高频记录一键填入 |

### Tier 3 — 可裁剪

| 功能 | 说明 |
|---|---|
| 日历热力图 | 视觉效果好但非核心，保留为 Dashboard 下方控件 |
| 预算管理 | 与心理学主题关联弱，移除独立页面，仅在设置中保留简要 |
| 数据导入导出 | 保留，低频但必要 |

## 不包含

- 多用户/账号
- 银行对接
- 投资/理财
- 复杂的周期账单
