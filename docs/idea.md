# 心情收支簿 — 项目概念

> 基于消费心理学理论的智能记账与欲望管理工具。

## 核心理念

帮助我们**看见消费心理模式、暂停冲动、清醒选择**。

核心隐喻：每次守住冲动 = 一束**星光** → 积累成长。

## 心理学理论

### 消费五型（Kahneman 双系统 + Dittmar 消费文化）

| 类型 | 驱动 | 说明 |
|------|------|------|
| 必要消费 | System 2 | 维持基本生存运转 |
| 价值消费 | System 2 | 对齐长期目标、自我成长 |
| 情绪消费 | System 1 | 情绪状态的消费投射 |
| 冲动消费 | System 1 | 无计划即时决策 |
| 意外消费 | — | 突发不可控支出 |

### 欲望管理
- **欲望冷却**：AI 分析 → 设定冷却期(1h~30d) → 冷静后决定
- **星光**：每次守住冲动得一颗星，同时抵御金额计入心愿进度
- **心愿**：储蓄目标，通过月度预算结余转入实现

### 月度预算
- 设定每月消费上限
- 超支形成亏空需优先填平

## 核心功能

- AI 自然语言记账（消费五型 + 8 种心情）
- 消费可视化（扇形图 + 心情分析 + 14日流图 + 月历热力图）
- AI 财务报告 + 心理分析 + 对话助手
- 心愿管理 + 星光激励 + 欲望冷却系统
- 月度预算追踪
- 6 种固定配色 + 动态心情主题
