# 心情收支簿 — 项目概念

> 基于消费心理学理论的 AI 智能记账与欲望管理工具。

---

## 1. 产品定位与一句话描述

**一句话描述：** 记录每一笔，看见情绪与金钱的隐秘关联。

**产品定位：** AI 驱动的消费心理学工具。不是传统的流水记账本，而是帮助用户**看见消费心理模式、暂停冲动、清醒选择**的自我认知工具。

**核心隐喻：** 每次面对消费冲动时的清醒选择 = 一束**星光** → 积累成长。

---

## 2. 心理学理论基础

### 2.1 Kahneman 双系统理论（Dual-System Theory）

Daniel Kahneman 在《思考，快与慢》中提出人类思维存在两个系统：

| 系统 | 特征 | 消费表现 |
|------|------|----------|
| **System 1（快系统）** | 直觉、自动、情绪化、不费力 | 冲动消费、情绪消费——看到就买、深夜刷直播下单、心情不好犒劳自己 |
| **System 2（慢系统）** | 理性、分析、控制、费力 | 必要消费、价值消费——预算内的房租水电、经过比较的课程投资 |

**本工具的应用：** 消费五型分类直接基于双系统理论。冲动消费和情绪消费对应 System 1，必要消费和价值消费对应 System 2。欲望冷却机制本质上是为 System 2 争取时间——通过强制冷静期，让理性系统有机会介入快系统的自动决策。

### 2.2 自我决定理论（Self-Determination Theory, SDT）

Deci & Ryan 的 SDT 提出人类有三种基本心理需求：**自主性（Autonomy）**、**胜任感（Competence）**、**关联感（Relatedness）**。

**本工具的应用：**
- **自主性：** 星光机制让用户自己选择"守住"还是"释怀"，不是强制禁止，而是赋予选择权
- **胜任感：** 成长轨迹展示守住率、守住金额、星光总数，让用户感受到自我控制的进步
- **关联感：** 心愿功能让克制与有意义的长期目标关联（旅行、学习等）

### 2.3 心理账户理论（Mental Accounting）

Richard Thaler 提出人们对金钱进行非理性的心理分类，不同来源/用途的钱被放入不同的"心理账户"。

**本工具的应用：**
- 消费五型和收入分类本质上是对心理账户的科学化梳理
- 月度预算设定"消费上限"，超支形成"亏空"——这个亏空的概念直接来自心理账户中的"损失厌恶"
- 心愿金额来自"克制回收"（抵御冲动的金额 + 预算结余），创造了新的正向心理账户
- 分账单（Project）功能允许用户为不同场景（春节旅游、游戏开支等）建立独立账户

### 2.4 控制点理论（Locus of Control）

Julian Rotter 提出个体对事件结果的归因方式：内控（我能控制结果）vs 外控（结果由外部决定）。

**本工具的应用：**
- 通过 AI 分析帮助用户识别消费的心理驱动因素（情绪补偿、社交压力、限时促销等），从"我控制不住自己"转向"我理解了我的触发因素"
- 欲望冷却中的反思问题引导用户从外控归因转向内控归因
- "守住"的次数和金额积累强化内控信念

## 3. 消费五型详解

消费五型是本工具的核心分类体系，基于 Dittmar 消费文化理论与 Kahneman 双系统理论。

### 3.1 必要消费（Necessity）

| 维度 | 内容 |
|------|------|
| **定义** | 维持生存和基本运转的支出 |
| **驱动系统** | System 2（理性决策） |
| **典型场景** | 房租/房贷、水电煤气、基础饮食（在家做饭/食堂）、通勤交通、基础医疗 |
| **心理学依据** | 马斯洛需求层次理论的底层需求（生理需求 + 安全需求）。这些消费是生存必需的，即使完全理性的人也必须在这些项目上支出。 |
| **识别关键词** | "必须""水电""房租""通勤""物业""社保" |
| **图标** | 🏠 home |
| **颜色** | 蓝色 #3b82f6 |

### 3.2 价值消费（Value）

| 维度 | 内容 |
|------|------|
| **定义** | 对齐长期目标、促进自我成长的支出 |
| **驱动系统** | System 2（理性决策） |
| **典型场景** | 在线课程/培训班、专业书籍、健身房年卡、技能工具订阅、健康体检 |
| **心理学依据** | 马斯洛自我实现需求。SDT 中的胜任感需求——通过学习和发展获得成长。这类消费是对未来的投资，ROI 体现在长期而非即时。 |
| **识别关键词** | "课程""学习""提升""投资自己""书" |
| **图标** | 📈 trending-up |
| **颜色** | 绿色 #10b981 |

### 3.3 情绪消费（Emotional）

| 维度 | 内容 |
|------|------|
| **定义** | 由情绪状态驱动的消费，可能是正向庆祝（开心请客）或负向补偿（焦虑购物、难过买衣服） |
| **驱动系统** | System 1（直觉/情绪驱动） |
| **典型场景** | 开心时请朋友吃饭庆祝、焦虑时淘宝扫货、难过时买甜食、疲倦时 buy expensive coffee |
| **心理学依据** | 情绪调节理论（Emotion Regulation Theory）——人们使用消费作为调节情绪的手段。Gross 的情绪调节模型指出，人们可能通过情境选择（去商场）或反应调节（购物获得愉悦）来管理情绪。这与消费心理学中的"零售疗法"（Retail Therapy）高度一致。 |
| **识别关键词** | "心情不好""犒劳""庆祝""奖励自己""安慰" |
| **图标** | ❤️ heart |
| **颜色** | 玫红 #f43f5e |

### 3.4 冲动消费（Impulsive）

| 维度 | 内容 |
|------|------|
| **定义** | 无计划即时决策的消费，事后常后悔 |
| **驱动系统** | System 1（突发驱动） |
| **典型场景** | 深夜刷直播下单、凑满减买不需要的东西、看到"限时优惠"不假思索下单、超市排队区随手拿的零食 |
| **心理学依据** | 即时满足偏差（Present Bias）——人类天生偏好即时奖励而低估未来回报。这也是"延迟满足"（Mischel 棉花糖实验）的经典场景。Sternberg 的冲动消费模型指出三个要素：突然的购买冲动、对冲动缺乏抗拒、为当下满足而购买。 |
| **识别关键词** | "冲动""没忍住""半夜""刷到""直播间""限时" |
| **图标** | ⚡ zap |
| **颜色** | 琥珀 #f59e0b |

### 3.5 意外消费（Unexpected）

| 维度 | 内容 |
|------|------|
| **定义** | 突发意外不得不支出的消费，属于外部事件触发 |
| **驱动系统** | 外部事件（非自主决策） |
| **典型场景** | 手机摔碎维修、突发急症看病、车被刮花维修、罚款缴费、管道漏水维修 |
| **心理学依据** | 外部控制点（External Locus of Control）——这类消费不由个人意志决定，是对外部不可控事件的被动反应。Coping Theory 中的问题聚焦应对（Problem-focused Coping）——为解决问题而不得不支出的费用。 |
| **识别关键词** | "坏了""摔了""看病""急症""罚款""突发""维修" |
| **图标** | ⚠️ alert-triangle |
| **颜色** | 橙色 #f97316 |

## 4. 收入分类说明

与支出五型采用心理学分类不同，收入采用**传统务实分类**。这是因为收入来源的心理意义远不如消费行为复杂——收入更多是"钱从哪里来"的事实问题，而非心理决策问题。

| 分类 | 定义 | 典型来源 | 图标 | 颜色 |
|------|------|----------|------|------|
| **工资** | 固定劳动报酬 | 月薪、年终奖、绩效奖金 | 💵 banknote | 绿 #22c55e |
| **兼职** | 额外劳动所得 | 副业、外快、自由职业 | 💼 briefcase | 青 #14b8a6 |
| **理财** | 被动投资收益 | 利息、分红、租金、基金收益 | 📈 trending-up | 蓝 #3b82f6 |
| **红包** | 赠送性收入 | 微信红包、礼物、父母/亲友给的钱 | 🎁 gift | 红 #ef4444 |
| **其他** | 其他来源的收入 | 报销、二手卖出的钱、退税 | … more-horizontal | 灰 #6b7280 |

**历史说明：** 在早期版本中，收入也曾尝试使用心理学五型（劳动收入、增值收入、馈赠收入、惊喜收入、回流收入），但从 v3.0 起简化为传统分类，更符合用户的日常认知习惯。

## 5. 欲望管理理论

### 5.1 延迟满足（Delay of Gratification）

**理论来源：** Walter Mischel 著名的"棉花糖实验"——能够延迟满足的儿童在成年后更成功。

**本工具的应用：** 心愿 × 星光机制的核心。用户将即时的消费冲动延迟，把克制带来的满足感（星光）和一个更大的长期目标（心愿）关联。每次延迟满足不是"失去"，而是向心愿更进一步。

### 5.2 执行意图（Implementation Intention）

**理论来源：** Peter Gollwitzer 提出，与其说"我要少花钱"，不如制定"如果遇到 X 情况，我就做 Y"的具体计划。

**本工具的应用：**
- 欲望冷却机制就是执行意图的具体实现："如果我有消费冲动，就启动冷却；冷却结束后，再决定是否购买"
- AI 分析后的反思问题帮助用户形成个性化的 if-then 计划
- 冷却时间的选择（1h~30d）本身就是一种执行意图的承诺

### 5.3 自我控制资源模型（Ego Depletion / Strength Model）

**理论来源：** Roy Baumeister 提出自我控制像肌肉——可以消耗也可以锻炼。

**本工具的应用：**
- **不会惩罚冲动消费：** 释怀/放过了就是放过了，不加道德评判
- **强化成功经验：** 每次守住 → 星光+1 → 可视化积累 → 建立自我效能感
- **成长轨迹：** 展示守住率、守住总金额，让用户看到自己自控力的成长
- 冷却机制在控制消耗最大的时刻（冲动高峰期）提供暂停，帮用户度过耗尽期

## 6. 心愿 × 星光机制

### 6.1 心愿（JarGoal）

**定义：** 用户设定的长期储蓄目标或物质目标。

**数据结构：**
- 名称（如"北海道的雪"）
- 目标金额
- 当前积累金额
- 描述（为什么想要——价值锚定）
- 颜色标识

**资金来源：**
1. 每次守住消费冲动，对应的金额自动计入关联的心愿
2. 月度预算结余（盈余可转入心愿）
3. 未来可能扩展的手动存入

### 6.2 星光（Stars）

**定义：** 克制冲动的荣誉称号，是次数而非金额的累积。

**核心区别：**
- 星光 = 次数（荣誉标记）：每次守住 +1，全局累积，不关联具体金额
- 心愿金额 = 金额（实际储蓄）：每次守住时，抵御的金额同时计入心愿进度

**设计哲学：** 一个用户可能抵御了 10 次小额冲动（共 500 元）和 1 次大额冲动（5000 元）。两者的星光价值相同（各+1），但心愿金钱贡献不同。星光强调的是"每一次清醒选择的荣誉感"，而非金钱数字。

### 6.3 StarJar 可视化

**视觉设计：**
- 环形进度条：外圈显示心愿金额达成进度
- 渐变描边：通过 SVG radialGradient 实现立体光泽
- 星光粒子：守住的事件以金色五角星漂浮在环形周围
- 点击星光：弹出 Popup 查看当时的守住记录（想买什么、省下多少钱、当时的反思）
- 每颗星有独立的浮动动画（不同的延迟和周期），营造星空氛围

## 7. 月度预算理念

### 7.1 预算设定

每月可设定一个消费上限金额。这是一个软性约束——不强制禁止消费，但提供实时的进度可视化。

**设计原则：**
- 不惩罚超支，但追踪亏空
- 预算剩余可视化（进度条颜色从绿色→琥珀→红色逐级警示）
- 盈余可转入心愿，创造正向激励

### 7.2 亏空机制

当本月支出超过预算时，系统记录亏空（Deficit），需在后续月份优先填平。这是心理账户理论中"损失厌恶"的温和应用——不是真实的债务，而是一个提醒。

### 7.3 预算统计

- 首页：四象限统计卡（收入/支出/结余/预算），预算栏显示剩余金额和百分比进度条
- AI 助手：财务报告 Tab 中独立的预算进度卡片
- AI 助手：对话 Tab 中的数据概况中包含预算剩余

## 8. 完整功能列表

### 8.1 记账功能
- **AI 自然语言记账：** 输入自然语言描述（"中午吃饭花了35块，心情还不错"），AI 自动解析出类型、金额、分类、日期、心情
- **百度语音记账：** 点击录音按钮，语音转文字后 AI 解析记账
- **手动记账：** 点击分类图标 + 金额，手动创建交易记录
- **常用记录模板：** 根据历史高频交易自动生成快捷模板
- **三步骤流程：** 输入 → AI 解析确认 → 手动微调保存
- **心情标记：** 每笔记账可选 8 种心情（开心/平静/一般/难过/焦虑/愤怒/兴奋/疲惫）
- **分账单归属：** 交易可归属到特定分账单（Project），如"春节旅游"

### 8.2 数据可视化
- **消费类型环形图（Donut）：** 展示消费五型的金额占比
- **消费心情饼图（Pie）：** 展示不同心情状态下的消费金额占比
- **14 日收支流图（双 Area Chart）：** 收入（绿色）和支出（红色）的双面积图，显示最近 14 天的收支趋势
- **心情时间线：** 横向滚动的时间线，展示过去 14 天每天的心情图标和支出金额
- **月历热力图（Calendar Heatmap）：** 支出/收入双视图，颜色深浅表示消费/收入多少，点击日期查看当天汇总，支持左右滑动切换月份
- **消费分类柱状图（Bar Chart）：** AI 助手柱状图展示消费五型金额排行
- **心情 × 消费柱状图：** AI 助手心理 Tab 展示不同心情下的消费金额
- **AI 生成图表数据：** 所有图表基于 IndexedDB 实时数据，按选定月份动态计算

### 8.3 AI 助手
- **财务报告 Tab：** 支出分类柱状图 + 预算进度 + AI 生成的月度财务报告（Markdown 格式，温暖语气）
- **心理分析 Tab：** 心情 × 消费柱状图 + AI 消费心理学分析（情绪-消费关联、改善建议）
- **对话助手 Tab：** 带数据上下文的自由对话，AI 基于用户财务数据回答（预算建议、情绪消费分析等）
- **快捷提问：** 预设的常用问题（"我这个月开心的时候花了多少？""焦虑时最常买什么？"）
- **报告可复制：** 生成的财务报告和心理分析可一键复制

### 8.4 欲望管理
- **心愿（JarGoal）：** 创建和管理长期储蓄目标，StarJar 环形进度可视化
- **欲望冷却：** AI 分析消费冲动 → 用户选择冷却时间（1h~30d）→ 冷却倒计时 → 到期重评估
- **提前守住：** 冷却中即可确认"守护"（"不等了，现在就守住"）
- **重评估流程：** 冷静后选择：守住（获星光+金额计入心愿）、购买（标记已购买）、再冷静一下
- **AI 冲动分析：** 分析冲动类型（情绪/冲动/不确定）、渴望程度 1-5、必要性 1-5、风险因素、建议冷却时长、反思引导问题
- **成长轨迹：** 守住率、守住总金额、星光总数、事件时间线（支持筛选已守住/已释怀）

### 8.5 主题系统
- **动态心情配色：** 8 种心情各对应一种主题色，3 种跟随策略（最多心情/最新消费/全天适应）
- **固定配色：** 6 种预设（暖琥珀/森绿/海蓝/玫瑰粉/薰衣草/日落橙）
- **全局联动：** 主题色影响页面背景渐变、卡片色阶、按钮颜色、Aurora 极光背景

### 8.6 设置与管理
- **API 配置：** DeepSeek API Key（AES-GCM 加密存储）、Base URL、模型名称、连接测试
- **语音识别：** 百度语音 API Key 和 Secret Key 配置、免费额度 5 万次/年
- **收支分类：** 查看/新建/删除自定义分类、选择图标和颜色、分类描述浮层提示
- **月度预算：** 设定/编辑本月预算
- **分账单（Project）：** 创建/删除分账单、选择图标和颜色
- **数据管理：** 导出全部数据（JSON）、导出交易记录（CSV）、导入数据（JSON）、清除所有数据

### 8.7 交互与体验
- **粒子特效：** 点击空白区域溅射彩色粒子
- **Canvas 粒子网络：** 80 个透明金色粒子在背景缓慢移动、相互连接
- **Aurora 极光背景：** 三个主题色的 radial-gradient 叠加，15s 呼吸动画
- **封面动画：** 物理引擎驱动的浮动图标（心情+分类图标碰撞反弹）+ 金色光环按钮
- **键盘快捷键：** Ctrl+K 快速触发记账 FAB 按钮
- **新手引导：** 无数据时显示欢迎页，包含消费五型介绍、三步开始指引
- **交易列表筛选：** 按类型、心情、分类、日期范围、关键词搜索
- **交易编辑/删除：** 点击交易弹出编辑模态框，确认删除弹窗
- **iOS 安全区适配：** Safe Area Insets 适配（底部导航、记账 FAB）

## 9. 命名哲学

本工具刻意回避传统财务记账的"冷冰冰"话术，采用温暖、非评判的命名体系。

| 传统记账 | 心情收支簿 | 设计意图 |
|----------|-----------|----------|
| 克制消费 / 忍住不买 | **守住** | 主动选择，而非被动忍耐。守是力量而非软弱 |
| 克制失败 / 放纵了 | **释怀 / 放过了** | 不评判、不惩罚。冷静后仍想要的可能确实值得 |
| 存钱罐 / 储蓄目标 | **心愿** | 消费克制不是为存而存，而是为了一个真正想要的目标 |
| 统计数据 / 历史记录 | **成长轨迹** | 不是冷冰冰的数字，而是自我认知和成长的记录 |
| 超出预算 / 超支 | **亏空** | 一个需要关注和填平的状态，而非道德评判 |
| 记一笔账 | **记录心情** | 消费是心情的表达，每一笔都是一刻心灵的记录 |
| 收入 / 支出 | **收 / 支** | 保持简洁但去财务化 |

## 10. 不包含的功能（设计取舍）

以下功能**明确不包含**在心情收支簿中，以避免功能膨胀：

- **多用户/账户系统：** 不做注册登录。所有数据本地存储，隐私优先
- **银行同步/账单导入：** 不支持自动同步银行数据。心情收支簿关注的是消费心理学维度，而非完整财务追踪
- **多币种支持：** 仅支持 CNY（人民币）。如需其他币种可修改设置中的 currency 字段
- **预算分类拆分：** 月度预算不拆分到具体消费类型，仅设总额
- **投资组合追踪：** 不做股票/基金净值追踪。理财仅作为收入类型记录
- **账单提醒/还款功能：** 不做账单日期提醒
- **社交分享：** 不做消费记录的社交分享功能
- **AI 模型切换（多供应商）：** 仅支持 OpenAI 兼容 API（DeepSeek、OpenAI 等），不做供应商特定适配
- **移动端原生 App（React Native）：** 纯 PWA Web 应用
