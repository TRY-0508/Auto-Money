# 心情收支簿 — 项目概念

## 一句话描述

基于消费心理学理论的情绪化记账与自我觉察工具。

## 核心心理学理论

### 四型消费框架（基于 Kahneman 双系统 + Dittmar 消费文化理论）

Kahneman 提出人类决策有两套系统：**System 1**（快速、直觉、情绪化）和 **System 2**（缓慢、理性、分析性）。消费行为往往由 System 1 驱动，产生情绪化、冲动型支出。

结合 Dittmar 的消费文化理论（消费是身份建构和情绪调节的工具），我们将消费分为四类：

| 类型 | 系统驱动 | 特征 | 示例 |
|---|---|---|---|
| **必要消费** | System 2 | 维持生存和基本运转，几乎无情绪色彩 | 房租、水电、基础饮食 |
| **价值消费** | System 2 | 对齐长期目标和个人成长，带来满足感 | 课程、健身、书籍、体检 |
| **情绪消费** | System 1 驱动 | 由情绪状态触发，可能是正向庆祝或负向补偿 | 焦虑时暴食、开心时请客、难过时买衣服 |
| **冲动消费** | System 1 突发 | 无计划、即时决策，事后常后悔 | 深夜刷直播下单、凑满减买了一堆没用的 |

### 消费决策评估框架（核心创新）

**核心问题**：同样是消费欲望，如何区分「值得追求的长期目标」和「应该克制的冲动」？

我们引入一个 AI 辅助的**四维评估模型**，在用户记录任何消费欲望时进行评估：

| 维度 | 量表参考 | 评估内容 |
|---|---|---|
| **时间持久性** | 延迟满足（Mischel） | 这个欲望持续多久了？一周后你还会想要吗？ |
| **价值留存度** | 心理账户（Thaler） | 这笔钱花出去后还能收回多少？是消耗品还是资产？ |
| **机会成本觉知** | 执行意图（Gollwitzer） | 为了它你愿意放弃什么？哪些消费可以减少？ |
| **事后后悔预测** | 预期后悔（Loomes & Sugden） | 买了之后你有多大可能后悔？不买呢？ |

基于评估结果，AI 将欲望分为两类：

- **潜在目标（潜在的价值消费）**：欲望持久、价值可留存、机会成本可接受 → 进入积攒瓶作为攒钱目标
- **待测试冲动（可能的情绪/冲动消费）**：突发性强、情绪驱动明显、事后后悔概率高 → 进入冷静事件流程

**注意**：这个分类不是绝对的。一个欲望可能同时具有两类特征（比如 CS 饰品：价值可留存但购买时机可能是冲动的）。此时系统让用户看到 AI 的分析，自行决定走哪条路径。

### 自我调节理论 + 积攒瓶

基于 **延迟满足（Mischel 棉花糖实验）** 和 **执行意图（Gollwitzer）**：设定"如果-那么"计划能显著提升目标达成率。

积攒瓶机制采用**四步流程**：

1. **记录欲望**：用户记录任何购买冲动（自由描述 → AI 分析 + 心理学量表）
2. **AI 评估分类**：AI 基于四维模型给出分类建议（潜在目标 / 待测试冲动）
3. **分流处理**：
   - 潜在目标 → 创建积攒瓶目标（设定金额目标）
   - 待测试冲动 → 创建冷静事件（设定冷静周期）
4. **冷静事件流程**：冷静期等待 → 到期 AI 辅助重新评估 → 克制成功得星星 → 星星+金额投入积攒瓶

### 冷静事件系统

**创建阶段**（AI 辅助）：
- 用户自由描述想买什么、为什么想买
- AI 分析并返回：
  - 消费类型判定（情绪/冲动/不确定）+ 信心度
  - 渴望程度建议（1-5，基于语言情绪强度分析）
  - 风险因素识别（深夜决策、情绪补偿、社交压力等）
  - 建议冷静周期（基于类型和金额）
  - 2-3 个引导性反思问题
- 用户确认或调整评估结果，开始冷静

**等待阶段**：
- 事件锁定，显示倒计时
- 显示 AI 生成的反思问题，帮助用户在冷静期思考

**重评估阶段**（冷静期结束后）：
- 展示原始评估 vs 当前感受对比
- AI 辅助分析欲望变化
- 用户决定：克制成功 / 还是想买 / 再冷静

**失败处理**：
- 冷静后依然想要 → 可选择「标记为已购买」或「再次冷静」
- 如果标记为已购买，可跳转记账
- 这不是失败，冷静期的意义是过滤纯冲动，如果一个欲望经过充分冷静后依然强烈，可能确实有合理性

### 星星与积攒瓶

- 每次克制成功获得 1 颗星星
- 克制的金额累加到对应目标的已攒金额
- 星星是可视化克制的累积，金额是实际储蓄的量化
- 达到目标金额触发达成动画

## 核心功能

| 功能 | 说明 |
|---|---|
| **AI 记账** | 自然语言输入 → AI 自动提取金额、心情、四型分类、日期、描述 |
| **心情 × 消费可视化** | 彩虹比例条 + 心情胶囊 + 四型分布饼图 |
| **AI 心理分析** | 基于四型框架分析消费模式，给出心理学建议 |
| **想法记录与评估** | 记录消费欲望 → AI 四维评估 → 分类建议（目标/冲动）|
| **积攒目标管理** | 设定长期目标金额 → 克制成功累积星星和金额 → 进度可视化 |
| **冷静事件系统** | AI 辅助创建（类型判定+渴望度+风险因素+反思问题）→ 冷静锁 → 到期重评估 → 成功/失败分流 |
| **AI 对话** | 带心情 + 四型上下文，可追问消费心理学问题 |

## 不包含

云同步、多用户、银行对接、复杂投资理财
