## 二、详细改进方案

### 2.1 消费分类心理学化 + 补齐意外消费

**现状**：当前支出分类共有 5 个系统预设：必要消费、价值消费、情绪消费、冲动消费、其他。其中「其他」是兜底分类，实质上是为了兼容传统记账习惯。另外 `icons.tsx` 中还保留了大量传统分类图标（餐饮、交通、购物、医疗等）——这些是旧版遗存。

**改进**：

1. **删除传统分类残骸**：从 `icons.tsx` 中移除 `PRESET_CAT_ICONS` 中传统分类的映射（餐饮、交通、购物、娱乐、住房、医疗、教育、通讯、日用、报销等），但保留图标库本身（Lucide 图标仍可用于自定义分类）。

2. **五型消费分类体系**：在四型基础上增加「意外消费」，形成完整的心理学分类：

| 分类 | 英文 | 图标 | 颜色 | 驱动系统 | 说明 |
|------|------|------|------|----------|------|
| 必要消费 | Necessity | `home` | `#3b82f6` 蓝 | System 2 | 维持生存和基本运转 |
| 价值消费 | Value | `trending-up` | `#10b981` 绿 | System 2 | 对齐长期目标，自我投资 |
| 情绪消费 | Emotional | `heart` | `#f43f5e` 红 | System 1 | 由情绪触发，正负向皆有 |
| 冲动消费 | Impulsive | `zap` | `#f59e0b` 琥珀 | System 1 | 无计划、即时决策 |
| 意外消费 | Unexpected | `alert-triangle` | `#f97316` 橙 | — | 突发意外支出（维修、医疗急症） |

3. **收入分类保持不变**：工资、兼职、理财、红包、其他。收入确实难以与情绪直接挂钩，保留传统务实的分类体系。

4. **删除「其他」兜底**：心理学五型已覆盖所有消费场景，不再设「其他」分类。用户确实需要的可通过自定义分类补充。

**涉及文件**：
- `src/db/seed.ts` — 修改 EXPENSE_CATEGORIES
- `src/lib/icons.tsx` — 清理 PRESET_CAT_ICONS
- `src/types/index.ts` — 无类型变更（Category 是通用的）

### 2.2 冲动冷却时间手动调整

**现状**：冷却时间仅有两个来源：(1) 默认 24 小时硬编码（`JarPage.tsx:131`）；(2) AI 分析结果中的 `suggestedCooldown`。用户无法自行调整。

**改进**：
- 在「记录消费冲动」表单中，AI 分析结果下方增加冷却时间选择器
- 预设选项：6小时 / 12小时 / 1天 / 2天 / 3天 / 7天
- 默认值：AI 建议值（如有）→ 否则 24 小时
- 用户可在确认前点击切换
- 冷却进行中也可修改剩余时间（加速或延长）

**涉及文件**：
- `src/pages/JarPage.tsx` — 增加冷却时间选择器 UI + 状态管理

### 2.3 配色方案可配置

**现状**：Dashboard 页的 `moodKey` 取的是 `moodStats[0]`（即本月数量最多的心情），然后用它设置整页背景。这导致如果某月 3 笔开心 2 笔焦虑，整月就是开心色——但其实最新一笔消费可能是焦虑的。

**改进**：
1. **多种配色策略**，在设置页可切换：
   - `most-frequent`：本月频次最高的心情（当前行为）
   - `latest`：最新一笔消费的心情
   - `neutral`：始终使用中性色调（暖奶油）
   - `adaptive`：根据当天的累计心情全天动态变化

2. Settings 类型扩展：
   ```typescript
   interface Settings {
     // ... 现有字段
     colorScheme: 'most-frequent' | 'latest' | 'neutral' | 'adaptive'
   }
   ```

3. Dashboard 中读取 `settings.colorScheme` 来决定 `moodKey` 的计算方式。

**涉及文件**：
- `src/types/index.ts` — Settings 接口增加 `colorScheme` 字段
- `src/lib/constants.ts` — DEFAULT_SETTINGS 增加默认值
- `src/pages/Dashboard.tsx` — 配色策略逻辑
- `src/pages/Settings.tsx` — 增加配色方案设置 UI
- `src/db/index.ts` — 无 schema 变更（Settings 是 key-value 存 JSON）

### 2.4 恢复每月预算 + 盈余/亏空机制

**现状**：`budgets` 表和数据 hooks 存在，但设置页没有预算管理 UI。Dashboard 也不展示预算进度。预算功能之前被删去了。

**改进**：

1. **恢复预算管理 UI**：在设置页增加「月度预算」section，允许：
   - 设定当月总预算金额
   - 按分类设定子预算（可选）
   
2. **Dashboard 增加预算卡片**：
   - 进度环显示已用/总额
   - 剩余天数均摊提示
   - 分类预算进度条

3. **盈余/亏空机制（核心新增）**：
   - **盈余**：月末若实际支出 < 预算，差额自动转入「心愿积攒」中的第一个心愿（或用户选定的心愿）
   - **亏空**：月末若实际支出 > 预算，差额记录为「亏空积攒」，这是一个负数心愿
   - **亏空优先规则**：在有亏空未填平时，新产生的星光（克制冲动）只能用于填平亏空，不能用于积攒心愿
   - 月度结算：每月1日自动触发（或手动触发）

4. **数据模型扩展**：
   ```typescript
   interface Deficit {
     id: string
     amount: number        // 亏空金额
     yearMonth: string     // 产生月份
     remainingAmount: number // 剩余待填平金额
     status: 'active' | 'filled'
     createdAt: number
   }
   ```
   DB 新增 `deficits` 表。

5. **心愿积攒中的盈余注入**：
   - 盈余时弹出确认弹窗：将 ¥XXX 转入心愿？
   - 用户可选择心愿或跳过
   - 已转入的盈余金额直接加到目标的 `currentAmount`，并增加等额星光

**涉及文件**：
- `src/types/index.ts` — 增加 Deficit 接口
- `src/db/index.ts` — 增加 deficits 表、升级 schema v5
- `src/db/hooks.ts` — 增加 useDeficits hook
- `src/pages/Settings.tsx` — 增加预算管理 section
- `src/pages/Dashboard.tsx` — 增加预算卡片展示
- `src/pages/JarPage.tsx` — 心愿页面显示亏空状态
- `src/lib/stats.ts` — 增加预算统计函数

### 2.7 卡片底色差异化

**现状**：所有 `.card` 共享同一套背景（`rgba(255,255,255,0.5)` + `backdrop-blur`），所有卡片看起来一样，缺乏层次。

**改进**：引入卡片色阶系统，根据功能角色为卡片分配不同的底色。

| 角色 | 类名 | 底色 | 用途 |
|------|------|------|------|
| 品牌卡 | `.card-accent` | 琥珀色极浅底 `rgba(245,158,11,0.06)` | 心情 Banner、预算概览 |
| 数据卡 | `.card-stat` | 暖白半透明 `rgba(255,255,255,0.7)` | 收入/支出/结余统计 |
| 图表卡 | `.card-chart` | 纯白略不透明 `rgba(255,255,255,0.85)` | 饼图、柱状图 |
| 列表卡 | `.card-list` | 极淡灰底 `rgba(248,247,245,0.6)` | 交易列表、时间线 |
| 交互卡 | `.card-interactive` | 与背景接近但有悬浮变化 | 可点击卡片 |

暗色模式对应调整。

**设计原则**：
- 每张卡片与相邻卡片有可感知但不刺眼的色彩差异
- 深色背景 < 浅色背景（信息承载越多的卡片越浅，装饰性的可以深一点）
- 同一个功能区的卡片底色一致
- 色差控制在 `ΔE ≈ 3-5`（人眼刚好可感知但不刺眼）

**涉及文件**：
- `src/index.css` — 新增卡片色阶 CSS 类
- 所有使用 `.card` 的组件 — 按角色替换为对应的色阶类

### 2.8 丰富数据可视化图表

**现状**：已有 — Recharts 饼图（支出分类）、彩虹条（心情比例）、心情胶囊、14天时间线、月历热力图、SVG donut ring（心愿进度和冷却）。

**改进**：引入更多图表类型，全面替换文字描述为图形表示。

#### 新增图表清单

| 图表 | 位置 | 类型 | 说明 |
|------|------|------|------|
| 月度收支趋势 | Dashboard | 折线图 | 30天支出/收入双线 |
| 五型消费分布 | Dashboard + AI 助手 | 环形图 | Donut + 中心文字，五色分区 |
| 心情×消费柱状图 | Dashboard + AI 助手 | 横向柱状图 | 各心情下的消费金额对比 |
| 预算消耗进度环 | Dashboard | SVG 环形 | 已用/总额 + 剩余天数 |
| 早晚消费对比 | AI 助手 | 分组柱状图 | 上午/下午/晚上的消费分布 |
| 周消费日历 | Dashboard 可切换 | 周历热力图 | 替代或补充当前月历 |
| 分类消费趋势 | AI 助手 | 堆叠面积图 | 五型消费随时间变化 |

#### 视觉风格要求
- **色彩**：5 色心理分类色为主，辅助用中性色
- **柔和**：圆角、阴影、透明度营造「软」的感觉
- **清晰**：不堆叠过多数据系列
- **动画**：图表加载时带淡入动画
- **标签**：关键数据点带数值标注

**涉及文件**：
- `src/pages/Dashboard.tsx`
