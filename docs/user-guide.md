# 心情收支簿 — 使用手册

## 快速入门

### 1. 配置 AI（可选但推荐）
进入「设置 → API 配置」，填入 DeepSeek API Key。配置后可以使用 AI 智能记账解析、财务报告和心理分析。

### 2. 记一笔
在首页点击「+」按钮或右上角「记一笔」，可以选择：
- **文字输入**：描述你的消费（如"中午吃饭花了35块，心情一般"），AI 会自动解析出金额、分类、心情
- **语音输入**：说话即可（需配置百度语音）
- **手动填写**：直接选择分类和金额

### 3. 查看分析
- **首页**：扇形图（消费类型/消费心情）+ 14日收支流 + 心情时间线 + 月历热力图
- **AI 助手**：财务报告（柱状图+预算进度）+ 心理分析（心情×消费关联）+ 对话助手

## 核心概念

### 消费心理五型
| 类型 | 说明 |
|------|------|
| 必要消费 | 维持生存和基本运转（房租、水电、基础饮食） |
| 价值消费 | 对齐长期目标、促进自我成长（课程、书籍） |
| 情绪消费 | 由情绪状态驱动的消费（开心请客、焦虑购物） |
| 冲动消费 | 无计划即时决策（深夜刷直播下单） |
| 意外消费 | 突发意外支出（维修、急症看病） |

### 心情系统（8 种）
开心 · 平静 · 一般 · 难过 · 焦虑 · 愤怒 · 兴奋 · 疲惫

每笔记账时可选心情，用于后续分析消费与情绪的关联。

### 月度预算
在「设置 → 月度预算」中设定每月消费上限。首页和 AI 助手中可实时查看预算剩余进度。

### 心愿 × 星光
- **心愿**：你想要达成的储蓄目标（旅行基金、大件物品）
- **星光**：每次面对消费冲动时选择「守住」，获得星光奖励
- 星光不关联具体金额，它是你自我控制的荣誉标记

### 欲望冷却
遇到让你犹豫的消费冲动？
1. 去「心愿 → 欲望冷却」记录冲动
2. 用 AI 分析你的消费心理
3. 设定冷却时间（1小时~30天）
4. 冷静后再决定：守住（获星光）或释怀

## 各页面说明

### 首页
- **统计卡片**：收入/支出/结余/预算四象限
- **消费分布**：消费类型扇形图 + 消费心情扇形图
- **14日收支流**：收入（绿）和支出（红）的双面积图
- **心情时间线**：过去 14 天的心情记录
- **月历热力图**：支出/收入双视图，点击日期查看当天汇总
- **交易列表**：筛选、搜索、编辑、删除

### AI 助手
- **财务报告**：柱状图 + 预算进度 + AI 生成月度报告
- **心理分析**：心情×消费柱状图 + 详细数据 + AI 心理建议
- **对话助手**：自由提问，AI 基于你的数据回答

### 心愿
- **心愿**：创建和管理储蓄目标，StarJar 环形进度可视化
- **欲望冷却**：记录冲动→AI 分析→冷静期→重评估
- **成长轨迹**：防守率/防守金额/星光总数 + 事件时间线

### 设置
- API 配置 · 语音识别 · 主题配色 · 收支分类 · 月度预算 · 分账单 · 数据管理

## 主题配色
- **动态心情**：主题色跟随当月主导心情自动变化

## 常见问题

**Q: 分类怎么只有这几个？**
A: 消费使用心理学五型分类，收入使用传统五分类。如果需要自定义分类，在「设置 → 收支分类」中可以新建。

**Q: 星光和心愿金额的关系？**
A: 星光是你克制冲动的次数（荣誉标记），每次守住时对应的金额也会计入心愿进度。两者同时增加。

**Q: 预算剩余怎么处理？**
A: 预算超支需优先填平亏空（记录在「心愿」页中）。
