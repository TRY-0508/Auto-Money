# 心情收支簿 — 使用手册

## 欢迎

心情收支簿是一款基于消费心理学理论的 AI 智能记账工具。它与传统记账 App 完全不同——不追求"全面财务追踪"，而是帮你**看见消费中的心理模式、暂停冲动、清醒选择。**

所有数据存储在浏览器本地，无需注册、无需登录。

---

## 快速开始（3 步）

### 第 1 步：记第一笔

打开应用后，点击右下角的 **"+"** 按钮或顶部的 **"记一笔"**，选择消费类型和心情，记录第一笔。

也可以直接输入文字描述，让 AI 自动解析——例如输入"中午吃饭花了35块，心情还不错"，AI 会帮你自动识别类型、金额和心情。

### 第 2 步：配置 AI（推荐）

进入「设置 → API 配置」，填入 DeepSeek API Key（从 [platform.deepseek.com](https://platform.deepseek.com) 获取）。

配置后可以使用的增强功能：
- 自然语言记账自动解析
- 月度财务报告生成
- 消费心理分析
- 对话式财务助手
- 消费冲动 AI 分析

### 第 3 步：发现模式

使用几天后，回到首页查看消费分布图、心情时间线、月历热力图，开始发现自己的消费心理模式。

## 核心概念详解

### 消费心理五型

每一笔支出都被归类到以下五种类型之一：

| 类型 | 图标 | 说明 | 举例 |
|------|------|------|------|
| **必要消费** | 🏠 | 维持生存和基本运转 | 房租、水电、基础饮食、通勤 |
| **价值消费** | 📈 | 对齐长期目标、促进自我成长 | 课程、专业书籍、健身年卡 |
| **情绪消费** | ❤️ | 由情绪状态驱动的消费 | 开心请客、焦虑购物、难过买甜食 |
| **冲动消费** | ⚡ | 无计划即时决策 | 深夜刷直播下单、凑满减买不需要的 |
| **意外消费** | ⚠️ | 突发意外不得不支出 | 手机摔碎维修、突发急症看病 |

**如何判断：** 你可以自己选择，也可以让 AI 通过文字描述判断。例如描述中说"突然""没忍住""半夜" → 冲动消费；"必须""房租" → 必要消费。

### 心情系统（8 种）

每笔记账时可以标记此刻的心情：

😊 开心 · 😌 平静 · 😐 一般 · 😢 难过 · 😰 焦虑 · 😡 愤怒 · 🤩 兴奋 · 😴 疲惫

**心情有什么用？**
- 首页的心情时间线展示你过去 14 天的情绪变化
- 消费心情饼图展示不同心情下的消费金额占比
- AI 心理分析可以发现"焦虑时是否更爱消费""什么时候消费最开心"等模式
- 动态配色：界面会随你当月主要心情变换主题色

### 月度预算

在「设置 → 月度预算」中设定每月的消费上限。

- **首页** 的统计卡中实时显示预算剩余和进度条
- **AI 助手** 的财务报告中包含预算执行分析
- 超支会记录为**亏空**，在后续月份优先填平

预算不是惩罚性的——它只是帮你建立消费边界感的工具。

### 心愿 × 星光

这是心情收支簿最独特的机制。分为两部分：

**心愿（JarGoal）：** 你真正想要实现的长期目标（旅行基金、大件物品、学习预算）。心愿有目标金额和当前进度。

**星光（Stars）：** 每次面对消费冲动时选择"守住"，获得 1 颗星光。星光不关联金额——它是对你**每一次清醒选择的荣誉标记**。每一次守住都有同等的星光价值，无论金额大小。

**它们如何关联：**
1. 你在「欲望冷却」中记录一个消费冲动（例如一件 ¥800 的衣服）
2. 经过冷却期后，选择"守住"
3. 星光 +1（全局计数器）
4. ¥800 自动计入你关联的心愿进度

**StarJar 可视化：** 每个心愿有一个环形进度条，进度条周围漂浮着金色的星光粒子（每颗代表一次守住）。点击星光可以查看当时的记录。

### 欲望冷却

遇到让你犹豫的消费冲动时：

1. 去「心愿 → 欲望冷却」点击「记录冲动」
2. 详细描述你想买什么、为什么想买、现在的心情
3. 点击「AI 心理分析」，AI 会分析你的冲动类型（情绪/冲动/不确定）、渴望程度、必要性、风险因素，并给出反思问题
4. 选择冷却时间（1 小时到 30 天）
5. 在这段时间里冷静思考
6. 冷却期满后重新评估：
   - **守住**：获得星光，金额计入心愿
   - **仍然想要**：标记为已购买（没有惩罚）
   - **再冷静一下**：重新进入冷却

**提前守住：** 冷却中也可以直接选择守住——"不等了，现在就守住"。

## 各页面详解

### 首页（Dashboard）`/`

#### 心情 Banner
页面顶部的渐变横幅，根据你当月主要的心情显示不同的问候语和名言。旁边的图标为你当月最常出现的心情图标。

#### 统计四象限
收入和支出数字（带环比变化百分比），结余（收入和支出的差值），预算剩余（带彩色进度条）。

#### 消费类型分布（Donut 环形图）
消费五型的金额占比。中间显示当月总支出。下方显示 Top 4 分类。

#### 消费心情分布（Pie 饼图）
不同心情状态下的消费金额占比。帮助你发现"在哪种情绪下花钱最多"。

#### 14 日收支流（双面积图）
绿色面积代表收入，红色面积代表支出。显示最近 14 天的每日收支变化趋势。

#### 心情时间线
横向滚动的时间线展示过去 14 天每天的心情图标和支出金额。有心情标记的日子显示对应心情图标，没有的显示"—"。快速一览你的情绪变化。

#### 月历热力图（可展开）
点击"展开月历"显示日历视图。支持支出/收入双视图切换：
- 颜色越深表示消费/收入越多
- 点击某一天查看当天的收支汇总
- 支持左右滑动切换月份
- 今天的日期有金色边框标记

#### 交易列表
- **筛选栏：** 按全部/支出/收入、心情、分类、日期范围筛选，支持关键词搜索
- **汇总行：** 显示当前筛选条件下的总笔数、总收入、总支出、总结余
- **列表：** 按日期分组，每条记录显示分类图标、分类名称、描述、心情图标、金额
- **操作：** 点击记录编辑，悬停显示删除按钮
- **编辑模态框：** 可修改类型、金额、分类、日期、描述、心情、分账单

#### 分账单切换
如果创建了分账单（如"春节旅游"），首页顶部会显示分账单切换器。选择某个分账单后，整个首页只显示该分账单下的数据。

#### FAB 记账按钮
右下角的"+"浮动按钮。点击打开记账模态框。也可用快捷键 `Ctrl+K` 触发。

### AI 助手（AIAssistant）`/ai`

三个 Tab：

#### 财务报告
- **统计卡：** 本月支出、收入、预算、预算剩余
- **支出分类柱状图：** 消费五型金额排行
- **预算进度条：** 已用/剩余可视化（绿色→琥珀→红色逐级变化）
- **AI 报告：** 点击「生成财务报告」获取 AI 撰写的月度分析，包含总体评价、收支概览、支出排行 Top 3、预算执行、实用建议
- **复制按钮：** 可一键复制报告内容

#### 心理分析
- **统计卡：** 同上
- **心情 × 消费柱状图：** 每种心情下的总消费金额，颜色各不相同
- **AI 心理分析：** 点击「生成心理分析报告」获取消费心理学顾问的分析，包含不同情绪状态下的消费特征、情绪性消费迹象识别、改善建议
- **使用前提：** 支付记录需要标记心情才能生成分析

#### 对话助手
- **数据概况：** 支出/收入/预算剩余三卡片
- **对话区：** 自由提问，AI 基于你的财务数据回答
- **快捷提问：** 初始显示 4 个推荐问题
- **上下文感知：** AI 知道你的月度收支、分类分布、心情统计
- **清除对话：** 底部「清除对话」按钮重置会话

### 心愿（JarPage）`/jar`

三个 Tab，切换时有淡入动画：

#### 心愿
- **创建心愿：** 输入名称、目标金额、描述
- **StarJar 展示：** 环形进度条 + 星光漂浮粒子
- **管理：** 悬停显示删除按钮

#### 欲望冷却
- **冷却中：** 蓝色标识，倒计时环形进度（颜色从蓝→橙→红逐渐变化），显示描述、金额、冲动类型、渴望程度。可提前守住或删除
- **等待确认：** 琥珀色呼吸动画边框，显示渴望/必要度评分。点击「去看看」进入重评估
- **记录冲动表单：** 描述输入 → AI 分析 → 查看分析结果（类型/建议冷却/渴望度/必要性/风险因素/反思问题） → 选择冷却时长 → 关联心愿 → 开始冷却

#### 成长轨迹
- **统计卡：** 守住率（百分比）、守住总金额、星光总数
- **时间线筛选：** 全部 / 已守住 / 已释怀
- **事件列表：** 每条显示状态标签、描述、金额、关联心愿、反思笔记、日期

### 设置（Settings）`/settings`

六个 Section，每项都是独立的玻璃卡片：

#### API 配置
- DeepSeek API Key（密码框，已有配置时显示"已配置"）
- Base URL（默认 `https://api.deepseek.com/v1`，可替换为 OpenAI 等其他兼容端点）
- 模型名称（默认 `deepseek-chat`）
- 「测试连接」按钮：调用 `/models` 端点验证，显示连接状态
- 「保存」按钮：将 API Key 加密后存储

#### 语音识别
- 供应商切换：百度语音 / 不使用
- 百度语音：API Key + Secret Key
- 链接到百度智能云控制台
- 免费额度：5 万次/年

#### 主题配色
- **配色模式：** 动态心情（主题随心情变） / 固定配色
- **动态策略（3 选 1）：**
  - 最多心情：当月出现次数最多的心情
  - 最新消费：最近一笔有心情的消费
  - 全天适应：按当日最新消费的心情
- **固定配色（6 选 1）：** 暖琥珀 / 森绿 / 海蓝 / 玫瑰粉 / 薰衣草 / 日落橙（带三色预览）

#### 月度预算
- 显示当月预算金额或「设定本月预算」按钮
- 编辑：输入金额 → 保存

#### 收支分类
- 支出分类和收入分类分开显示
- 每个分类显示图标（带背景色）和名称
- 系统分类有描述浮层：悬停显示详细说明
- 自定义分类显示删除按钮（红色 ×）
- 「+ 新建」按钮：选择支出/收入类型 → 选择图标 → 输入名称

#### 分账单
- 创建分账单：选择图标 → 颜色 → 输入名称
- 分账单用于给交易打标签（如"春节旅游""游戏开支"）
- 首页有分账单切换器可单独查看
- 删除分账单不会删除交易，但会清除交易的归属

#### 数据管理
- 导出全部数据 (JSON)：包含交易、分类、预算、设置
- 导出交易记录 (CSV)：仅交易记录，BOM 头确保 Excel 正常识别中文
- 导入数据 (JSON)：将之前导出的 JSON 文件恢复
- 清除所有数据：确认弹窗 → 清空所有 IndexedDB 表 → 刷新页面

## 记账流程详解

### 方式 1：AI 文字记账（推荐）

1. 点击「记一笔」→ 选择「文字」模式
2. 输入自然语言描述，例如：
   - "中午吃饭花了35块，心情还不错"
   - "这个月在得到买了个写作课299"
   - "收到工资8000块"
   - "逛街看到一双鞋特别喜欢899，晚上犹豫要不要买"
3. 点击「AI 解析」
4. 查看 AI 解析结果（类型、金额、分类、日期、描述、心情、置信度）
5. 点击「确认并编辑」进入手动微调页面
6. 如需修改，手动调整后点击「保存」

**常用记录模板：** 如果之前记录过类似的支出，modal 底部会显示快捷模板，点击即可直接解析。

### 方式 2：语音记账

1. 点击「记一笔」→ 选择「语音」模式
2. 点击「点击开始录音」（需先配置百度语音 API Key）
3. 说出消费描述
4. 点击停止或自动结束后，显示识别文字
5. 点击「AI 解析」进行记账

**注意：** 需要 Chrome 或 Edge 浏览器；百度语音免费额度为 5 万次/年。

### 方式 3：手动记账

1. 点击「记一笔」→ 选择「文字」→ 点击「手动填写」
2. 选择支出/收入
3. 输入金额
4. 选择分类（5 列网格，可新建自定义分类）
5. 选择日期（默认今天）
6. 输入备注（可选）
7. 选择心情（可选）
8. 选择分账单（可选）
9. 点击「保存」

## 常见问题（FAQ）

**Q: 心情收支簿和普通记账 App 有什么区别？**
A: 普通记账关注"花了多少钱"，心情收支簿关注"为什么花钱"——每一笔消费都被归入心理学五型分类，同时记录消费时的心情。它不是财务工具，而是自我认知工具。

**Q: 星光和心愿金额是什么关系？**
A: 星光计数克制次数（荣誉），心愿金额记录克制下来的金额（储蓄）。两种同时增加，但意义不同。10 次守住小额和 1 次守住大额，星光相同，金额不同。

**Q: AI 需要花钱吗？**
A: 需要 DeepSeek API Key。DeepSeek 提供免费额度，日常使用通常不会超出。如果不配置 API Key，仍然可以使用手动记账和所有非 AI 功能。

**Q: 不配置 AI 能用哪些功能？**
A: 手动记账、首页图表、心情记录、心愿管理、冷却计时、数据导入导出——几乎所有数据展示和管理功能都无需 AI。AI 仅用于记账解析、财务报告、心理分析、对话助手的智能部分。

**Q: 我的数据存在哪里？安全吗？**
A: 所有数据存储在浏览器的 IndexedDB 中，完全本地。没有服务器、没有注册、没有上传。你可以随时导出备份或清除。AI API Key 使用 AES-GCM 加密后存储。

**Q: 消费五型分类我记不住，怎么办？**
A: 使用 AI 文字记账——只需自然描述，AI 会自动判断五型分类。分类悬停时也会显示描述说明。最核心的区分是：它是让你变好的（价值）还是当下必须的（必要）还是情绪驱使的（情绪/冲动）。

**Q: 预算超支了会怎样？**
A: 超支会记录为亏空，UI 上显示红色警示。但不会有任何惩罚——它只是一个提醒。系统关注的是"觉察"而非"管制"。

**Q: 释怀（没守住）会有什么后果？**
A: 没有惩罚。你可以标记为"已购买"或者在成长轨迹中记录为"释怀"。守住率是一个参考数据，不是成绩单。我们相信清醒后的选择——即使选择购买，也是经过思考的选择。

**Q: 主题色变了是什么原因？**
A: 如果你在动态心情模式下，主题色会跟随当月主要心情或最新消费心情变化。如果不想变，去「设置 → 主题配色」切换到固定配色。

**Q: 可以在手机上用吗？**
A: 完全可以。心情收支簿是移动优先设计的 PWA 风格 Web 应用，适配手机浏览器。访问 GitHub Pages 部署地址即可使用。

**Q: 如何备份和迁移数据？**
A: 去「设置 → 数据管理」，点击「导出全部数据 (JSON)」，下载备份文件。在新设备上打开应用，进入设置 → 导入该 JSON 文件即可。

**Q: 支持多设备同步吗？**
A: 目前不支持自动同步。可以手动导出/导入 JSON 文件在不同设备间迁移数据。

## 技巧与建议

### 记账建议
- **记录心情是关键：** 消费金额只是一个数字，心情标记才是心理分析的素材
- **使用 AI 省心：** 自然语言描述比手动选分类快得多，尤其是日常重复消费
- **常用模版：** 高频消费自动出现在模板列表中，点击即可快速记录

### 欲望管理建议
- **AI 分析越详细越准：** 描述冲动时，多写几个字——你的心情、为什么想买、之前是否犹豫过
- **不要跳过冷却：** 即使只有 1 小时，也比立即下单好
- **反思问题认真想：** AI 生成的反思问题是有针对性的，停下来想想

### 主题建议
- 如果情绪波动大，用**动态心情**模式感受自己的情绪颜色
- 如果需要稳定感，切换到**固定配色**

### 预算建议
- 第一个月不要设预算——先观察自己的消费模式
- 一个月后根据实际数据设定一个比当前支出低 10-20% 的目标
