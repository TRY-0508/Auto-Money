# 心情收支簿 — 实现状态

## v3.0 — 消费心理全面转型（当前）

### 新增/改进
| 模块 | 内容 |
|---|---|
| 五型消费分类 | 删除传统记账分类（餐饮/交通等），保留五类心理消费：必要/价值/情绪/冲动/意外 |
| 五型收入分类 | 基于自我决定理论+心理账户+控制点理论：劳动/增值/馈赠/惊喜/回流 |
| 冷却时间手动调整 | 记录冲动时可手动选择冷却周期（6h/12h/1天/2天/3天/7天），无需依赖AI |
| 配色方案 | 四种配色策略（最多心情/最新消费/中性色调/全天适应），设置页可选 |
| 月度预算 | 恢复预算管理，设置页可设定月度预算；Dashboard 和 AI 助手展示预算进度环 |
| 盈余/亏空机制 | 预算结余可转入心愿；超支形成亏空，星光优先填平亏空 |
| Dashboard 卡片化 | 四统计卡片（收入/支出/结余/预算）+ 五型扇形图 + 心情柱状图 + 30日面积图趋势 |
| AI 助手重设计 | 财务报告 Tab：统计卡片 + 双图表 + 预算进度；心理分析 Tab：柱状图 + 一览列表；对话 Tab：数据条 |
| 卡片色阶系统 | 五级卡片底色（stat/chart/list/accent/soft），视觉层次丰富柔和 |
| 数据可视化升级 | 新增 Recharts 面积图、柱状图；所有图表统一柔和配色风格 |

### 技术变更
| 模块 | 内容 |
|---|---|
| 数据库 | 升级至 schema v5，新增 `deficits` 表 |
| Settings 类型 | 新增 `colorScheme` 字段 |
| Deficit 类型 | 新增亏空数据模型 |
| CSS | 新增 `.card-stat`/`.card-chart`/`.card-list`/`.card-accent`/`.card-soft` 五个色阶类 |
